# 交给做 PPT 的 agent：交接说明

> 你拿到的 `outline.md` 是内容大纲，不是排版稿。请按下面的约束把它做成幻灯片。

## 1. 这是什么

- 本科毕业设计（FYP）的**组会进度汇报**，15 分钟，听众是导师和同组同学。
- 中文，11 页，16:9。
- 目的是"让听众知道这两周做了什么、结论是什么、还差什么"，不是产品发布。

## 2. 内容来源（唯一事实来源）

1. `meetings/2026-10-20/outline.md`（主结构，每页有要点和讲法）
2. `docs/handoff-2026-10-19.md`（所有已确认数字）
3. `docs/engineering-decision-register.md`（决策依据，ADR-006/007/008/017/018）

**数字必须与上面一致。** 如果某个数字在文档里找不到，或你觉得前后矛盾，**停下来问**，不要自己推算或四舍五入。

## 3. 硬性要求

| 项 | 要求 |
| --- | --- |
| 尺寸 | 16:9（13.333 × 7.5 英寸）|
| 每页文字 | ≤6 条要点，每条 ≤2 行；正文字号 ≥16 pt |
| 每页一个观点 | 标题就是那个观点，不要"背景介绍"式标题 |
| 数据来源 | 每个结果页底部一行小字标注来源文件 |
| 演讲备注 | 每页 2–4 句，含诚实的注意事项 |
| 图表 | 能用表格就不用图；要用图就保证数据标签清晰、不截断 |

## 4. 不要做的事

1. **不要改动任何数字**，包括小数位。
2. **不要删掉第 8 页（INT8）和第 10 页（心率/S1-S2 失败）**——这两页是刻意保留的，失败分析在答辩里是加分项。
3. **不要合并或拆分页面**，除非先说明理由。
4. **不要使用"国际领先""突破性"这类宣传词**；这个项目还没上板。
5. **不要声称任何硬件实测**（时延、电流、屏幕）——一项都没做过。
6. **不要放真实病人的录音或图像**；如需要波形示意，用合成信号或纯示意图。
7. 不要把 FP32 的数字和 INT8 的数字放在同一列直接比较——那是两类不同的事实。

## 5. 两个必须保持结构的页

**第 7 页（决策对比页）**必须是一张表：

- 行：三个候选（小 CNN+ESP32-S3 / TCN+更强 MCU / 树莓派）
- 列：FP32 AUROC、INT8 AUROC、INT8 体积、功耗与启动、结论
- 表下必须有：决策依据、验证计划、失败判据与回退

**第 8 页（INT8）**建议做成"前后对比"的视觉：旧配方 0.0937 → 新配方 0.0191，旁边标注 TCN 的 0.1433。
