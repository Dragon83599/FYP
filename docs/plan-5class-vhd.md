# 新方向实施计划：五分类瓣膜病（2026-10-23）

> 决策记录见 `docs/engineering-decision-register.md` 的 ADR-020。
> 本文只讲"怎么做"：预处理 → 特征 → 模型 → 评估 → 部署 → 时间线。

## 1. 数据集现状（已实测）

| 项 | 值 |
| --- | --- |
| 来源 | `github.com/yaseen21khan/Classification-of-Heart-Sound-Signal-Using-Multiple-Features-` |
| 规模 | 1000 个 WAV，5 类各 200（AS / MS / MR / MVP / N）|
| 格式 | 8 kHz、单声道、16-bit |
| 时长 | 1.16–3.99 s，中位 2.43 s |
| 重复 | 逐字节重复 0 个 |

**三个必须写进论文的限制**：
1. 无患者 ID → 只能做"同一录音不跨折"，不能声称患者级无泄漏；
2. 类别干净、来源混杂 → 高准确率部分来自"录音来源"差异，不是病理；
3. 无许可 → 只用于研究，不随论文发布原始音频。

## 2. 预处理流水线

每段录音依次做五步（全部可复现，参数写死）：

| 步骤 | 做法 | 参数 |
| --- | --- | --- |
| 1. 解包 | libarchive 读 `.rar` | 保持目录结构，类别来自文件夹名 |
| 2. 端点检测 | 短时能量 + 阈值，剪掉首尾静音 | 帧长 25 ms、跳 10 ms；阈值 = 噪声底 × 3 |
| 3. 带通滤波 | 4 阶 Butterworth 带通 | **20–1000 Hz**（与 ADR-002 一致）|
| 4. 归一化 | 每段 z-score | `(x-mean)/std`，与旧 `normalize_window` 相同 |
| 5. 切窗 | 2 s 窗、1 s 步进 | 短于 2 s 的录音**两端补零**；每类约 1–3 个窗 |

> 下采样：若特征用 4 kHz，则 8 kHz → 4 kHz 带限抽取（与旧流水线同一实现）。
> 若用 CWT/STFT，保留 8 kHz 分辨率更好，两种都跑一次对比。

## 3. 特征 × 模型：四条实验臂

目标不是"把所有方法都试一遍"，而是**回答一个问题**：在 1000 条、5 类、2.4 s 的数据上，
特征和模型各自贡献多少？

| 臂 | 特征 | 模型 | 目的 | 预期 |
| --- | --- | --- | --- | --- |
| **A1** | MFCC + Δ + ΔΔ（13 维，25 ms/10 ms） | 逻辑回归 / SVM | 复现数据集原论文的路线，作为下限基线 | 85–95% |
| **A2** | log-mel 谱图（64 mel，2 s） | 2D CNN（ResNet 结构） | 看"图像式"特征 + 深模型能到多少 | 90–98% |
| **A3** | 原始波形（4 kHz，8000 点） | 1D CNN（复用现有 `Small1DCNN`，改 5 类头） | 端到端，最贴近端侧部署 | 85–95% |
| **A4**（可选） | CWT 尺度图（Morlet，64 尺度） | 2D CNN（同 A2） | 与 A2 比：CWT 是否比 STFT 更适合心音 | 待测 |

**DWT**：作为 A1 的特征补充（各子带能量/熵），或单独做一小臂，用来和原论文的 MFCC+DWT 对齐。
**二阶谱（双谱）**：计算量大、维度高，**不建议作为主臂**；可作为"特征工程探索"的一小节。
**AOCT**：见第 7 节——目前无法确认它指什么，需你提供出处。

## 4. 评估协议

| 项 | 做法 |
| --- | --- |
| 划分 | 分层 5 折（按类别），**同一录音不跨折** |
| 指标 | **macro F1**（主指标）、每类 F1、混淆矩阵、准确率 |
| 为什么 macro F1 | 5 类均衡，但错分代价不同：把 AS 判成 N 比判成 MS 更严重，混淆矩阵必须看 |
| 不确定性 | 按录音 bootstrap 1000 次给 macro F1 的 95% CI |
| 必须报告 | 哪两类最容易混（预期 AS↔MS、MR↔MVP） |
| 禁止 | 用测试折选特征/模型/超参；所有选择只在训练折内做 |

## 5. 部署：板子怎么选

| 候选 | 算力 | 延迟（估） | 功耗 | 启动 | 结论 |
| --- | --- | --- | --- | --- | --- |
| **ESP32-S3**（已有代码）| 240 MHz，INT8 SIMD | 5 类小 CNN 约 20–150 ms | 0.4–0.5 W | <1 s | ✅ 若模型 ≤150k 参数，优先 |
| **树莓派 Zero（v1）** | ARM1176 1 GHz，**无 NEON** | 可能 300 ms–1 s | 0.6–1 W | 20–40 s | ❌ 不建议 |
| **树莓派 Zero 2 W** | Cortex-A53 ×4，有 NEON | 50–200 ms（TFLite）| 0.8–1.5 W | 20–30 s | ✅ 若要 Linux/Python |

**建议**：先按 ESP32-S3 的路线做（工具链已就绪、量化已打通）；如果 5 类模型超过 S3 的
RAM/时延预算，再切 Zero 2 W，并把模型导出为 TFLite。

## 10. 参考实现：知乎那篇"基于深度学习-树莓派的心脏疾病听诊"（已读全文）

文章全文已存档：`docs/refs/2026-10-23-zhihu-pcg-aoct-rpi-zero.pdf`。

### 10.1 他们做了什么

| 环节 | 做法 |
| --- | --- |
| 数据 | **4 个数据集合并**：Yaseen（5×200）、CinC2016、Kaggle2016、PASCAL |
| 预处理 | 2 阶 Butterworth **25–400 Hz** 带通 → 下采样到 **1 kHz** → 归一化到 [-1,1] → **2.5 s 窗、50% 重叠**切割 |
| 特征 | **二阶谱（双谱 / bispectrum）**，`polycoherence`（nfft=1024, nperseg=256, noverlap=100, fs=1000）→ 256×256 矩阵；试过等高线/热力图，结论是直接用双谱本人最好 |
| 模型 | "改进的 **AOCT** 卷积网络"：4 个 Conv2D+BN+ReLU+MaxPool 块 → Flatten → Dense → Softmax；输入 256×256×1；Adam 1e-3、batch 64、60 epoch |
| 结构 | **两级**：二分类（正常/异常）+ 四分类（AS/MS/MR/MVP，不含正常）|
| 结果 | 二分类 **96.77%**，四分类 **97%**（准确率）|
| 部署 | 树莓派 Zero + 1200 mAh 电池 + USB HUB HAT + 1.3" LCD HAT + 3.5mm 听诊器 + 外置声卡；h5 → **TFLite** 部署 |

### 10.2 对我们最有用的三点

1. **AOCT 不是某个公开标准架构**，就是他们自己命名的"4 个卷积块的 CNN"。你如果沿用这个名字，答辩时要能直接画出这 4 个块，而不是说"引用 AOCT"。
2. **双谱（二阶谱）特征确实可跑通**，且他们对比后认为比等高线/热力图更省算力——这给了我们一个明确的对照臂。
3. **Pi Zero + TFLite 的完整链路是通的**（h5 不能直接在 Pi 上加载，必须转 TFLite），这条经验可以直接复用。

### 10.3 他们方法里的三个漏洞（这就是我们可以做得更好的地方）

| 问题 | 说明 | 我们的做法 |
| --- | --- | --- |
| **窗口级随机划分** | 25000 训练 / 3000 测试是按**窗口**随机分的，而窗口来自同一段录音且 50% 重叠 → 训练集与测试集里几乎必然出现同一条录音的相邻窗口，**准确率被抬高** | **按原始录音分组划分**（GroupKFold），同一录音的窗口只出现在一折 |
| **只报准确率** | 没有每类 F1、没有混淆矩阵数值、没有置信区间 | 报 **macro F1 + 每类 F1 + 混淆矩阵 + bootstrap CI** |
| **四分类不含正常** | "97%" 是在 4 个异常类之间分，比 5 类简单 | 我们做**真正的 5 分类**，并额外报告"二分类门 + 四分类"两级方案作对照 |

### 10.4 由此调整实验臂

新增 **A5：双谱 + 2D CNN**，与 A2（log-mel）/ A4（CWT）形成"三种时频表示"的公平对比：

| 臂 | 特征 | 模型 | 目的 |
| --- | --- | --- | --- |
| A1 | MFCC+Δ | 线性/SVM | 下限基线 |
| A2 | log-mel | 2D CNN | 常规时频 |
| A3 | 原始波形 4 kHz | 1D CNN | 端到端 |
| A4 | CWT 尺度图 | 2D CNN | 变分辨率时频 |
| **A5** | **双谱 256×256** | **2D CNN（AOCT 式 4 块）** | 对标该文，验证高阶谱是否真的更好 |

**预期**：A5 在**随机窗口划分**下会得到 96–97%（复现他们的数字），但在**按录音分组划分**下会明显下降——这个"下降幅度"本身就是我们论文里最有价值的发现之一。
