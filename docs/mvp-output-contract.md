> 条款收缩 MVP 输出范围。本文定义"设备显示什么、以什么措辞显示、依据是什么"。
>
> 关联：ADR-008、ADR-007、ADR-011、ADR-015、`docs/handoff-2026-10-18.md`。

## 1. 一句话

设备对**波形**和**杂音筛查分数**负责；**心率作为估算值进入 MVP**（2026-10-18 决定，
见 ADR-008 补充）；**S1/S2 标注不进 MVP**。任何输出都不构成诊断。

## 3. 为什么心率也只能算估算

心率不需要 S1/S2 标签，但需要一个稳定的每拍事件序列。实测（`data/reports/heart-rate-circor.json`，
3152 条录音，参考心率由 CirCor 标注的 S1/S2 事件对给出）：

离线（标注区间掩码 + 全录音事件）：

| 分层 | n | 中位误差 | MAE | p95 | ±5 bpm 内 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 全部 | 3152 | 1.19 | 6.79 | 44.2 | 82.6 % |
| 参考心率 ≤120 | 2487 | 1.14 | 4.90 | 33.1 | 85.0 % |
| 参考心率 >120 | 665 | 1.41 | 13.85 | 67.8 | 73.8 % |

**设备条件**（C 实现、无标注掩码、32 事件历史）——这才应当被引用：

| 指标 | 数值 |
| --- | --- |
| 对参考心率 MAE | **8.14 bpm** |
| 与桌面版 ±2 bpm 一致率 | 41.5 % |
| 有效性门控判 `--` 的比例 | 1/3150（0.03 %） |

结论：**不得引用 1.19 bpm 的中位数来描述设备表现**。掩码的影响大于历史深度
（带掩码的 last-32 为 67.9 %）。

误差不是高斯型，而是"多数极准 + 少数灾难"：

| 分位 | p50 | p75 | p85 | p90 | p95 | p99 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 绝对误差（bpm） | 1.19 | 2.90 | 7.06 | **26.1** | **44.2** | 72.1 |

- \(\pm\)5 bpm 内 82.6 %；\(\pm\)10 bpm 内 86.5 %；
- **>10 bpm 占 13.5 %**（426 条），**>20 bpm 占 11.2 %**（354 条），最大 139 bpm；
- 按常见监护仪"±10 bpm 或 ±10 %"的判据，13.5 % 的读数不通过。

因此**不得用中位数 1.2 bpm 作为精度声明**：它描述的是最好的一半，不是设备表现。

尝试过的改进与判据（均失败，如实记录）：

| 尝试 | 结果 | 结论 |
| --- | --- | --- |
| 间隔规律性作为可信标志 | 阈值 0.7 可排除 44/55 个粗错，但只保留 46 % 录音，剩余仍有 6 % 粗错 | 拒收率过高，不可用 |
| 包络自相关估心率（不依赖 S1/S2 身份） | 同一 400 条抽样：MAE **14.48** vs 事件配对 6.86；>10 bpm 16.3 % vs 14.1 % | 更差，放弃 |

粗错中 99 条是"每拍只检出一个事件"导致心率减半，属检测环节的结构性错误，不是估计器细节。

## 4. 对固件的含义

当前固件（`firmware/`）只有：波形渲染占位、杂音推理占位（明确返回
`AI_STUB_STATUS_NOT_IMPLEMENTED`，概率 −1）。心率**尚未移植到 C**。

契约分两步生效：

1. **现在**：固件显示波形 + "murmur: n/a (no model)"，符合契约（不谎称有 AI、
   不显示未实现的心率）。
2. **心率移植后**：以 `HR ~<bpm>` 形式显示，事件数不足或值超出 30–220 bpm 时显示 `--`；
   S1/S2 默认仍不显示。

**移植的关键设计约束**：心率只需要稳定的事件时刻，**不需要 S1/S2 标签**，因此 C 端
可以省掉两状态动态规划，只做"带通 → 包络 → 自适应阈值 → 峰值与显著度 → 近峰合并 →
事件时刻"。验收必须包含"C 版心率 vs Python 版心率"的一致性对照，而不是只看代码能跑。

不做的事：不为了"看起来完整"而在固件里伪造心率或 S1/S2。

## 5. 验收与回退

验收：

- 显示层不存在任何"诊断"字样；
- 杂音分数出现时，同屏有"筛查提示"或等价限定；
- 心率出现时带"估算"字样，且不出现在导出的报告里；
- 关闭探头后设备仍能完成本地显示与推理（ADR-008 的边缘约束）。

回退：

- 若后续 S1/S2 在独立验证集上达到 0.80 且高心率互换 ≤0.20，才可按新 ADR 恢复展示；
- 若心率获得可验证的可信判据（例如逐拍一致性检查达到 ≥95 % 精确率），才可去掉"估算"限定；
- 任何恢复都必须保留 "不构成诊断" 的措辞。
