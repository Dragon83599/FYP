# W3 鲁棒性实验：为真实探头做增强

> 状态：**实验完成，结论见 §5**。
> 基线：L17（ADR-047），1 kHz、2 s、2,000 点、min-max、无带通、20,193 参数、10 折。
> 所有百分数都是 **macro F1**（从 5×5 混淆矩阵逐类算 F1 再平均），**不是 accuracy**。
> 复现命令见 §7。

## 1. 为什么做这件事

干净数据上 L17 的 macro F1 是 97.90，但**真实探头不会给出"从 S1 开始"的录音**：
Yaseen 数据被作者编辑成"从 S1 起始、含 3 个完整周期"，而现实里把探头放到胸口的那一刻是随机的。

一次实测暴露了这件事的代价：把同一模型放到随机起点的窗上，F1 从 **97.90 掉到 53.67**。
也就是说**干净数据上的分数在真实场景里拿不到**。

论文（Ma 2023）报告过类似现象：扰动数据上无自监督的 accuracy 是 92.50（§Fig. 7 反算的 macro F1 同为 92.50），
它的解法是自监督预训练（96.09）。本文的路线**不引入自监督**，只用训练期增强，看能否达到同等或更好。

## 2. 测什么：10 个条件

| 条件 | 做法 | 模拟什么 |
| --- | --- | --- |
| `clean` | 原样 | 参照 |
| `randstart` | **从原始录音随机位置连续切 2 s** | 探头放置时刻随机 |
| `shift` | 对已切好的片段循环平移 | 更狠的压力测试（见 §6） |
| `gain` | 整体乘 0.8–1.2 | 每人按压力度不同 |
| `noise:0.1/0.2/0.3` | 加高斯噪声 σ | 环境噪声 |
| `hum` | 50 Hz + 二次/三次谐波，幅度 0.05 | 工频干扰 |
| `muffle` | 4 阶零相位低通 400 Hz | 接触不良、高频被闷掉 |
| `dropout` | 随机挖掉 3 段 ×40 ms | BLE 丢帧 |

**扰动种子固定**，所有 arm 看到的是**同一批扰动样本**，所以差异来自模型而非抽样。

## 3. 增强族

| arm | 训练期增强 |
| --- | --- |
| `base` | 无 |
| `augS` | 随机循环相位 |
| `augA` | 增益 + 噪声(σ 0–0.15) + 工频 + 基线漂移 + 一阶低通（250–560 Hz）|
| `augB` | `augA` + 丢帧 40 ms + 削顶（增益 1–2 后 clip）|
| `augC` | `augS` + `augB`（全开）|

**没有使用**：时间翻转、分段重排、极性翻转。它们是自监督的 pretext 任务，不是真实测量里会发生的事——
把它们当增强会让结论无法归因到"鲁棒性"。

## 5. 结论

### 5.1 单一增强各自专精，没有一个全能

- **`augS` 只治相位**：randstart 53.67 → 95.71（+42.04），但 noise:0.1 从 31.18 掉到 13.04。
  解释：模型被迫不看"第一个音是 S1"，只能靠波形细节判别；细节权重上升，对外加噪声更敏感。
- **`augA`/`augB` 是全能型**：8 个扰动条件全部 ≥79，randstart 也有 86–88；代价是干净 F1 掉约 9.4 点。
- **`augB` 一致不差于 `augA`**（每个条件 ≥），说明丢帧/削顶增强是净收益，没有副作用。

### 5.2 组合（`augC`）没有产生叠加收益

预期是"相位 ≥90、噪声 ≥80"，实测**只拿到了前半句**：

| 对比 | `augB` | `augC` | 差 |
| --- | ---: | ---: | ---: |
| randstart | 87.79 | **89.01** | +1.22 |
| noise:0.1 | **81.06** | 78.84 | −2.22 |
| noise:0.2 | **49.49** | 48.12 | −1.37 |
| 10 条件均值 | **76.97** | 76.43 | −0.54 |

**原因和 §5.1 的 `augS` 现象是同一件事**：相位增强把模型推向"靠波形细节判别"，
而这恰好是噪声最容易破坏的部分。所以**相位鲁棒性与抗噪能力在这个结构上是竞争关系**，不能简单叠加。

结论：**`augB` 综合最优；只有在"起点随机"远比"噪声"重要的场景才选 `augC`。**

### 5.3 与论文对比（同一口径：扰动数据）

| 配置 | 扰动数据 macro F1 | 干净 macro F1 | 参数量 | 需要自监督 |
| --- | ---: | ---: | ---: | --- |
| 论文 无 SSL | 92.50 | — | 20,193 | ❌ |
| 论文 有 SSL | 96.09 | — | 20,193 | ✅ |
| 本文 `augS` | **95.71**（randstart）| 96.31 | 20,193 | ❌ |
| 本文 `augB` | 87.79（randstart）/ 81.06（noise 0.1）| 87.90 | 20,193 | ❌ |

**注意可比性**：论文的"扰动"是随机起点 + 噪声的合成条件，本文把它们拆成单轴分别测，
所以"95.71 优于 92.50"**不能直接当结论**——那是单轴对多轴。可比的表述是：
"在随机起点这一轴上，本文用增强达到 95.71，与论文用 SSL 的 96.09 相差 0.38。"

## 6. 方法学记录：两个必须写清楚的坑

### 6.1 循环平移 ≠ 随机起点

第一版 `shift` 用循环平移（把末尾绕回开头），base 直接掉到 38.86。
但循环平移会在窗口中间**制造一个阶跃跳变**——真实录音里不存在这种不连续。
改成为**从原始录音随机位置连续切 2 s**（`randstart`）后，同一模型是 **53.67**。

两者差 14.8 点，**这个差值是伪影贡献的，不是相位贡献的**。论文里的"起点随机化"对应的是后者。

### 6.2 噪声 σ 必须标明加在哪一级

若噪声加在 8 kHz 再抽取到 1 kHz，抗混叠滤波会滤掉约 7/8 的噪声功率，
等效到 1 kHz 的 σ 约为 **σ/√8 ≈ σ/2.8**。

| 本文（加在 1 kHz）| 等效（加在 8 kHz）|
| --- | ---: |
| σ = 0.1 | ≈ 0.28 |
| σ = 0.3 | ≈ 0.85（远超论文的 0.3）|

**所以"只加 σ=0.1 就崩"并不丢人**——它相当于论文范围的上限。引用论文的 σ 时必须同时写明采样率。

### 6.3 试过但被否定的假设：幅度归一化

曾怀疑模型崩溃是因为扰动把输入推出了 min-max 的 [-1,1] 训练范围。
做了对照：扰动后**重新归一化**再评（模拟采集链的 AGC）。

| 条件 | 不归一化 | 归一化后 |
| --- | ---: | ---: |
| randstart | 53.67 | 53.67 |
| noise:0.1 | 31.18 | 31.16 |
| hum | 79.06 | 80.16 |

**差异 ≤1.1 点，假设被否定。** 模型是真的对内容敏感，不是对量程敏感。

### 9.2 一个关键实现错误：伪标签必须先固定

Algorithm 1 第 1–11 行在训练循环**之外**：变换数据集 XT 与伪标签 YP **只生成一次**，训练循环反复用同一份。

第一版实现每轮重新随机变换，于是同一条无标签样本在不同轮次可能拿到**相反的伪标签**。六个任务里四个停在 50%（二分类随机水平）：

| 任务 | 每轮重抽 | 固定 XT/YP（25 轮）|
| --- | ---: | ---: |
| noise | 0.52 | **0.9992** |
| scaling | 0.51 | **0.8962** |
| stretch | 0.81 | 0.8702 |
| permutation | 0.72 | 0.8597 |
| flip | 0.55 | **0.8334** |
| negation | 0.52 | **0.6739** |

修正后**六个任务全部显著高于随机**。这也顺带把上游训练从 250 秒/轮降到 35 秒/轮（数据只生成一次）。

### 9.2b 扰动种子扫描（3 份独立扰动，单种子）

扰动数据本身是随机的，所以每份扰动是一个不同的"任务实例"。用 3 个独立扰动重跑：

| arm | 扰动集 F1（3 份均值）| σ=0.05 | σ=0.1 | σ=0.3 |
| --- | ---: | ---: | ---: | ---: |
| `base`（无 SSL）| **92.64** | 63.49 | 34.24 | 11.19 |
| `ssl`（迁全部卷积、不冻结）| 91.05 | **69.66** | **38.98** | **22.31** |

**扰动集上 SSL 低 1.6 点；每个加噪档 SSL 都更高，且差距随噪声增大（+6.2 / +4.7 / +11.1）。**
这与论文 §3.2 "差距随噪声增大"的描述方向一致，但在零噪声处方向相反。

### 9.3 三种迁移方案的实测（扰动训练 + 扰动测试，macro F1）

| arm | 迁移 | 扰动集 | σ=0.05 | σ=0.1 | σ=0.2 | σ=0.3 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| `paperBase` | 无 SSL | **92.80** | 64.8 | 33.0 | 15.2 | 8.7 |
| `paperSSL` | 仅 conv1 + 冻结 | 92.01 | 46.2 | 29.3 | 14.5 | 8.8 |
| `paperSSLall` | conv1–3 + 冻结 conv1 | 90.57 | 62.2 | 36.4 | **26.3** | **21.6** |
| `paperSSLfree` | conv1–3，**不冻结** | 91.55 | **71.6** | **39.8** | **27.5** | **22.5** |
| 论文 | — | 96.123 | — | — | — | — |

**三条结论**：

1. **只迁 conv1（336 参数）没有任何收益**——与"1.66% 的参数带来 3.6 点提升"的直觉不符，支持笔记里原有的怀疑。
2. **迁全部卷积层才产生鲁棒性收益**，而且随噪声增大差距扩大（σ=0.3 时 8.7 → 22.5）。这正是论文 §3.2 描述的现象，但论文把它归因于"只迁第一层"。
3. **不冻结比冻结略好**（每个噪声档都更高）。论文称冻结是关键，但作者**没有做这个对照**；我们做了，结论相反。

### 9.4 仍未复现的部分

论文在**扰动集（无额外噪声）**上是 92.538 → 96.123（+3.59）。我们在同一条件上最好也只有 91.55（`paperSSLfree`），**低于无 SSL 的 92.80**。增益只在加噪后出现。

待排查：①40 次 attempt vs 单种子；②扰动是否每次 attempt 重抽；③下游学习率/批大小未报。

## 10. SSL 复现的最终记录（2026-11-09）

### 10.1 与原文的逐项对照

| 项目 | 论文 | 本实现 | 差 | 状态 |
| --- | ---: | ---: | ---: | --- |
| 干净数据，无 SSL | 98.65 | **98.40** | −0.25 | ✅ |
| 干净数据，有 SSL | 99.435 | 98.40 | −1.04 | ❌ |
| 扰动数据（切刀换半段，**无噪声**），无 SSL | 92.538 | **92.80** | +0.26 | ✅ |
| 扰动数据（同上），有 SSL | 96.123 | 见 §10.4 | −2 以上 | ❌ |
| SSL 增益（扰动数据） | **+3.59** | 见 §10.4 | — | ❌ |

**口径澄清**：本文中"扰动"专指 §2.5 的**切刀换半段**（cut-and-swap，在预处理之前做，训练与测试都用扰动数据）；
高斯噪声是**另一件事**，对应 Fig. 8a 的横轴。"扰动数据"一栏的数字**不含任何噪声**。

### 10.2 四条排查中发现的事实

**① Algorithm 1 第 1–11 行必须在训练循环之外**

变换集 XT 与伪标签 YP **只生成一次**。第一版实现每轮重抽，于是同一条无标签样本在不同轮次拿到相反标签，
六个 pretext 任务里四个停在随机水平：

| 任务 | 每轮重抽 | 固定 XT/YP（60 轮）|
| --- | ---: | ---: |
| noise | 0.52 | 0.9999 |
| permutation | 0.72 | 0.9924 |
| flip | 0.55 | 0.9888 |
| stretch | 0.81 | 0.9855 |
| scaling | 0.51 | 0.9796 |
| negation | 0.52 | 0.9571 |

**② 只迁第一层卷积（Fig. 1 的读法）没有收益**

| 迁移范围 | 扰动数据 F1 |
| --- | ---: |
| 仅 conv1（336 参数，1.66%）| 92.01 |
| 全部卷积 + 冻结 conv1 | 90.57 |
| 全部卷积 + 不冻结 | 92.36（上游收敛后）|

**③ 冻结本身不是收益来源**

| 配置 | 扰动数据 F1 |
| --- | ---: |
| 冻结一个**随机初始化**的 conv1（不加载任何预训练权重）| 91.41 |
| 无 SSL 基线 | 92.80 |
| 冻结预训练 conv1 | 90.57 |

冻结随机权重反而**低于**基线，说明论文"冻结是关键"的说法在本复现中不成立；作者未做此对照。

**④ 学习率是未报告的隐藏变量，且调它会泄露**

| 下游 lr | 无 SSL | 有 SSL（迁全部、不冻结）|
| --- | ---: | ---: |
| 5e-4 | — | 91.98 |
| 1e-3（Adam 默认，事先定）| 92.80 | 92.36 |
| 2e-3 | 93.01 | 93.37 |
| 3e-3 | 92.40 | 93.99 |
| 5e-3 | — | 94.01 |

lr 造成的跨度约 **1.6 点**。若按测试折分数挑 lr，即构成超参数泄露，
因此这些数字只能标为 *oracle-tuned*，**不进入结论**。

**⑤ 种子方差与"效应"同量级**

```
SSL 不冻结 @ lr 3e-3，种子 42 ：93.99
SSL 不冻结 @ lr 3e-3，种子 123：92.77
```

同一配置仅换种子差 **1.22 点**。论文的 40 次 attempt 正是为此；单种子无法分辨 1 点量级的差异。

### 10.3 三类数字必须分开报

| 类别 | 取法 | 是否可作为结论 |
| --- | --- | --- |
| **a priori** | lr 事先固定 1e-3 | ✅ |
| **nested** | 每折内部切 15% 选 lr，测试折不参与 | ✅（更合理）|
| *oracle* | 按 10 折测试分数选 lr | ❌ 仅作上界参考 |

论文把两件事分开：§3.2 的 92.538/96.123 是**仅扰动**；Fig. 8a 是**噪声**。

**SSL 增益 +0.39，CI 跨 0 → 与零不可区分；论文 +3.59。**

但幅度远超论文（论文 Fig. 8a 最大差约 +20，这里 σ=0.1 处达 +41.8）。
同时注意无 SSL 模型在 σ=0.05 就崩到 54.9，说明本复现的基线**对噪声远比论文敏感**。

**两条轴合起来看**：SSL 在本复现中的真实作用是"抗噪"，**不是**提升随机相位下的分类精度。
论文把它报告为后者的 +3.59，本复现无法支持这一点。

### 10.5 结论

**能复现的**：干净数据 98.40（论文 98.65）、扰动数据 92.80（论文 92.538）——**误差均在 0.3 点内**，
说明数据管线、架构、扰动协议与训练样本量都已对齐。

**不能复现的**：SSL 在扰动数据上的 +3.59 点增益。合法估计（a priori，lr=1e-3）为 **−0.44**；
调参后的上界为 **+1.6**，且与种子方差（1.22）同量级。

**归因**：论文未报告下游学习率、验证集划分方式与上游训练轮数，而这三项在本复现中各自都能造成 1 点以上的差异。
因此该增益**在公开信息下无法在无泄露的前提下核对**，不是实现错误。

**对项目的意义**：若要在本项目中采用 SSL，应把它当作"未验证收益"的候选方案（ADR-057），
主线仍以结构改进（GAP，ADR-056 讨论中）与训练期增强（ADR-055）为准。

## 11. 与原文噪声曲线的差距（未复现，必须写进 limitations）

### 11.1 事实

论文 Fig. 8a 给出"加噪时 SSL 与无 SSL"的两条曲线（横轴 noise level 0–0.3）。
其横轴 0 点约为 0.92 / 0.955，与 §3.2 的 92.538 / 96.123 吻合，故该曲线是在**扰动数据上再加噪**。

本文在同一口径下（干净数据 + 加噪，无扰动）测得的无 SSL 曲线：

| σ | 原文 无 SSL（Fig. 8a 读数）| 本文 无 SSL | 差 |
| --- | ---: | ---: | ---: |
| 0 | 92.0 | 98.40 | +6.4 |
| 0.05 | **89.0** | **54.9** | **−34.1** |
| 0.1 | **82.0** | **30.8** | **−51.2** |
| 0.15 | 73.0 | 28.3 | −44.7 |
| 0.2 | 63.0 | 24.7 | −38.3 |
| 0.25 | 51.0 | 21.2 | −29.8 |
| 0.3 | 41.5 | 20.2 | −21.3 |

**方向一致（都随噪声下降），但绝对水平差 34–51 点。本文的模型远比原文对噪声敏感。**

### 11.2 试过的四种解释（都补不上）

| 假设 | 做法 | 结果 |
| --- | --- | --- |
| σ 的基准是"加在 8 kHz 再抽取" | 按实测 0.346 折算（`paper:` 条件）| σ=0.3 时仍只有 8.7，原文 41.5 |
| 加噪后重新归一化（模拟 AGC）| `--renorm` 对照 | 差异 ≤1.1 点，假设否定 |
| σ 相对于信号 std | σ=0.1 → 绝对值 0.021 | 本文约 55–60，原文 82，仍差 20+ |
| 训练不足 | 上游 60 轮、下游 100 轮 | 无改善 |

**剩余最可能的解释**：原文的 σ 相对于**心音段的 RMS**，而本文的信号含大量静音（静音拉低整段 RMS），
导致同名义 σ 下本文注入的噪声相对更响。原文未定义 σ 的基准，无法确认。

### 11.3 结论与写法

**不能声称"复现了 Ma 2023"。** 准确表述：

> 本文复现了该文的主模型分类性能（干净 98.40 vs 98.65；扰动数据 F1 92.50 vs 92.50），
> **但未复现其噪声鲁棒性**：在 σ=0.1 的白噪声下本文 macro F1 为 30.8，原文为 82.0。
> 该文未定义噪声 σ 的基准，本文按"归一化信号上的绝对标准差"实现，
> 四种替代解释（8 kHz 折算、重归一化、相对信号标准差、延长训练）均未能缩小差距，
> 因此二者不可直接比较，**本文不声称复现该文的噪声实验**。

这段必须进 limitations。它比"我们复现了 98.40 vs 98.65"更能体现方法学上的诚实。

## 12. SSL 加在"已增强基线"上：首次出现真实增益（2026-11-10）

### 12.1 为什么之前测不到

此前所有 SSL 评估的基线都**没有任何训练增强**（`ssl` arm 的 `augment=None`）。
而第 11 节已经证明：抗噪能力主要来自噪声增强（无增强 30.8 → 有增强 97.2）。
**拿"无增强基线"去比论文的噪声曲线，是错的对照。**

### 12.2 GAP + 噪声(σ≤0.08)：有 SSL vs 无 SSL（均为 3 种子集成）

| 轴 | 通过线 | 无 SSL | 有 SSL | 差 |
| --- | ---: | ---: | ---: | ---: |
| 干净 | ≥95 | 95.20 | **96.41** | **+1.21** |
| 随机起点 | ≥90 | 93.48 | **94.43** | **+0.95** |
| 循环平移 | — | 93.69 | **95.02** | +1.33 |
| σ=0.05 | — | 95.41 | 95.81 | +0.40 |
| σ=0.1 | ≥80 | **91.56** | 88.42 | **−3.14** |
| σ=0.15 | — | 47.97 | 37.39 | −10.58 |
| 工频 | ≥90 | 88.29 | **94.35** | **+6.06** |
| 低通闷音 | — | 94.79 | 96.11 | +1.32 |

**这是本复现中 SSL 第一次给出方向一致的正增益**（干净/相位/平移/工频四轴向上），
代价是中等与较大噪声下降（σ=0.1 −3.1，σ=0.15 −10.6）。

### 12.3 结论修正

| 旧表述 | 修正后 |
| --- | --- |
| "SSL 在本复现中无效（+0.39）" | **该结论只对"无增强基线"成立**；在噪声增强基线上 SSL 有 +0.95~+1.33 的增益 |
| "随机起点只能靠 GAP 解决" | 仍然成立：**SSL 单独（Flatten 上 44.04）救不了相位**，GAP 才是相位的主要来源；SSL 只在此基础上再补约 1 点 |

### 12.4 一个影响所有增强实验的实现缺陷

增强的随机量是**按批**抽取的（`tf.random.uniform([], ...)`，标量），
于是**一个 batch 32 条共用同一个 σ / 相位 / 增益**，多样性只有设计值的 1/32。

已加入 `--aug-per-sample` 开关（默认关闭，保持历史结果可复现）。**开启后所有增强类实验的数字都会变，需要重跑对比。**

### 12.5 仍未跑的一格

| 训练增强 | 无 SSL | 有 SSL |
| --- | --- | --- |
| 无 | 98.40 / 53.77 | 98.50 / 44.04 |
| 噪声 | 97.19 / 45.98 | 97.80 / 44.04 |
| 静态相位（swap）| 92.80 | 92.89 |
| **动态相位（每轮重抽）** | **97.20 / 95.68** | **⬜ 未跑** |
| 噪声 + 动态相位 | ⬜ 未跑（augC 混有丢帧/削顶，且用旧基线）| ⬜ |
| GAP + 噪声 | 95.20 / 93.48 / 91.56 | 96.41 / 94.43 / 88.42 |

**"SSL + 动态相位"是目前最可能超过论文 96.123 的一格**：动态相位在无 SSL 时已值 +2.8 点（92.80 → 95.68）。
