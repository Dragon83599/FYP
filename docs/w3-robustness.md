# W3 鲁棒性实验：为真实探头做增强

> 状态：**实验完成，结论见 §5**。
> 基线：L17（ADR-047），1 kHz、2 s、2,000 点、min-max、无带通、20,193 参数、10 折。
> 所有百分数都是 **macro F1**（从 5×5 混淆矩阵逐类算 F1 再平均），**不是 accuracy**。
> 复现命令见 §7。

## 1. 为什么做这件事

干净数据上 L17 的 macro F1 是 97.90，但**真实探头不会给出"从 S1 开始"的录音**：
Yaseen 数据被作者编辑成"从 S1 起始、含 3 个完整周期"，而现实里把探头放到胸口的那一刻是随机的。

一次实测暴露了这件事的代价：把同一模型放到随机起点的窗上，F1 从 **97.90 掉到 53.67**。
也就是说**干净数据上的分数在真实场景里拿不到**。

论文（Ma 2023）报告过类似现象：扰动数据上无自监督的 accuracy 是 92.50（§Fig. 7 反算的 macro F1 同为 92.50），
它的解法是自监督预训练（96.09）。本文的路线**不引入自监督**，只用训练期增强，看能否达到同等或更好。

## 2. 测什么：10 个条件

| 条件 | 做法 | 模拟什么 |
| --- | --- | --- |
| `clean` | 原样 | 参照 |
| `randstart` | **从原始录音随机位置连续切 2 s** | 探头放置时刻随机 |
| `shift` | 对已切好的片段循环平移 | 更狠的压力测试（见 §6） |
| `gain` | 整体乘 0.8–1.2 | 每人按压力度不同 |
| `noise:0.1/0.2/0.3` | 加高斯噪声 σ | 环境噪声 |
| `hum` | 50 Hz + 二次/三次谐波，幅度 0.05 | 工频干扰 |
| `muffle` | 4 阶零相位低通 400 Hz | 接触不良、高频被闷掉 |
| `dropout` | 随机挖掉 3 段 ×40 ms | BLE 丢帧 |

**扰动种子固定**，所有 arm 看到的是**同一批扰动样本**，所以差异来自模型而非抽样。

## 3. 增强族

| arm | 训练期增强 |
| --- | --- |
| `base` | 无 |
| `augS` | 随机循环相位 |
| `augA` | 增益 + 噪声(σ 0–0.15) + 工频 + 基线漂移 + 一阶低通（250–560 Hz）|
| `augB` | `augA` + 丢帧 40 ms + 削顶（增益 1–2 后 clip）|
| `augC` | `augS` + `augB`（全开）|

**没有使用**：时间翻转、分段重排、极性翻转。它们是自监督的 pretext 任务，不是真实测量里会发生的事——
把它们当增强会让结论无法归因到"鲁棒性"。

## 5. 结论

### 5.1 单一增强各自专精，没有一个全能

- **`augS` 只治相位**：randstart 53.67 → 95.71（+42.04），但 noise:0.1 从 31.18 掉到 13.04。
  解释：模型被迫不看"第一个音是 S1"，只能靠波形细节判别；细节权重上升，对外加噪声更敏感。
- **`augA`/`augB` 是全能型**：8 个扰动条件全部 ≥79，randstart 也有 86–88；代价是干净 F1 掉约 9.4 点。
- **`augB` 一致不差于 `augA`**（每个条件 ≥），说明丢帧/削顶增强是净收益，没有副作用。

### 5.2 组合（`augC`）没有产生叠加收益

预期是"相位 ≥90、噪声 ≥80"，实测**只拿到了前半句**：

| 对比 | `augB` | `augC` | 差 |
| --- | ---: | ---: | ---: |
| randstart | 87.79 | **89.01** | +1.22 |
| noise:0.1 | **81.06** | 78.84 | −2.22 |
| noise:0.2 | **49.49** | 48.12 | −1.37 |
| 10 条件均值 | **76.97** | 76.43 | −0.54 |

**原因和 §5.1 的 `augS` 现象是同一件事**：相位增强把模型推向"靠波形细节判别"，
而这恰好是噪声最容易破坏的部分。所以**相位鲁棒性与抗噪能力在这个结构上是竞争关系**，不能简单叠加。

结论：**`augB` 综合最优；只有在"起点随机"远比"噪声"重要的场景才选 `augC`。**

### 5.3 与论文对比（同一口径：扰动数据）

| 配置 | 扰动数据 macro F1 | 干净 macro F1 | 参数量 | 需要自监督 |
| --- | ---: | ---: | ---: | --- |
| 论文 无 SSL | 92.50 | — | 20,193 | ❌ |
| 论文 有 SSL | 96.09 | — | 20,193 | ✅ |
| 本文 `augS` | **95.71**（randstart）| 96.31 | 20,193 | ❌ |
| 本文 `augB` | 87.79（randstart）/ 81.06（noise 0.1）| 87.90 | 20,193 | ❌ |

**注意可比性**：论文的"扰动"是随机起点 + 噪声的合成条件，本文把它们拆成单轴分别测，
所以"95.71 优于 92.50"**不能直接当结论**——那是单轴对多轴。可比的表述是：
"在随机起点这一轴上，本文用增强达到 95.71，与论文用 SSL 的 96.09 相差 0.38。"

## 6. 方法学记录：两个必须写清楚的坑

### 6.1 循环平移 ≠ 随机起点

第一版 `shift` 用循环平移（把末尾绕回开头），base 直接掉到 38.86。
但循环平移会在窗口中间**制造一个阶跃跳变**——真实录音里不存在这种不连续。
改成为**从原始录音随机位置连续切 2 s**（`randstart`）后，同一模型是 **53.67**。

两者差 14.8 点，**这个差值是伪影贡献的，不是相位贡献的**。论文里的"起点随机化"对应的是后者。

### 6.2 噪声 σ 必须标明加在哪一级

若噪声加在 8 kHz 再抽取到 1 kHz，抗混叠滤波会滤掉约 7/8 的噪声功率，
等效到 1 kHz 的 σ 约为 **σ/√8 ≈ σ/2.8**。

| 本文（加在 1 kHz）| 等效（加在 8 kHz）|
| --- | ---: |
| σ = 0.1 | ≈ 0.28 |
| σ = 0.3 | ≈ 0.85（远超论文的 0.3）|

**所以"只加 σ=0.1 就崩"并不丢人**——它相当于论文范围的上限。引用论文的 σ 时必须同时写明采样率。

### 6.3 试过但被否定的假设：幅度归一化

曾怀疑模型崩溃是因为扰动把输入推出了 min-max 的 [-1,1] 训练范围。
做了对照：扰动后**重新归一化**再评（模拟采集链的 AGC）。

| 条件 | 不归一化 | 归一化后 |
| --- | ---: | ---: |
| randstart | 53.67 | 53.67 |
| noise:0.1 | 31.18 | 31.16 |
| hum | 79.06 | 80.16 |

**差异 ≤1.1 点，假设被否定。** 模型是真的对内容敏感，不是对量程敏感。

## 7. 复现

```bash
.venv/bin/python tools/ai/make_l17_arms_data.py          # 生成 L17 与各变体数据集
.venv-tf/bin/python tools/ai/w3_arms.py --arm base  --seeds 42 --fixed-epochs --epochs 100 --out data/reports/w3
.venv-tf/bin/python tools/ai/w3_arms.py --arm augS  --seeds 42 --fixed-epochs --epochs 100 \
    --compare data/reports/w3/base/report.json --out data/reports/w3
```

训练配方统一：Adam 1e-3、batch 32、**固定 100 轮（不早停）**。
不用早停是因为早停会让同一配置在折间波动 1.2 点（见 `docs/tasks/w2-repro-ma2023.md` §9.1b），
足以淹没本次要比较的差异。
