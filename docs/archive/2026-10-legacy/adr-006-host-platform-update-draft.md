### 2.1 候选方案

| 方案 | 核心原理 | 所需器件/软件 | 适用条件 |
| --- | --- | --- | --- |
| 0 维持现状 / 不引入新组件 | 主机只做采集、显示、回放、缓存和上传，AI 放手机或服务器 | 现有 PC/主机开发环境、手机或服务器推理 | 仅历史对照；不满足“推理必须边缘部署”的强制约束，不得作为最终方案或回退 |
| A ESP32-S3 | 单芯无线 MCU + 向量指令 + 外部 PSRAM | ESP-IDF、ESP-DL/TFLite Micro、ESP32-S3 模组 | 模型和 UI 中等、需要最快原型、单芯 RTOS 易测试 |
| B ESP32-P4 + C5/C6 | P4 负责 AI/显示，C5 或 C6 负责无线 | ESP-IDF、双芯 IPC、P4 开发板 + C5/C6 模组 | A 的计算、内存或显示不足；需要 MIPI 时选 C6，需要双频无线时选 C5 |
| C STM32N6 + 独立 BLE/Wi-Fi | M55 + 1 GHz NPU 负责推理，无线模块负责链路 B 和 BLE | STM32Cube、ST Edge AI、无线模块 SDK | A/B 被真实模型或算子证明不足，且 NPU 实际收益足够 |
| D Linux SoC/SBC | 通用 Linux 运行 AI、GUI、文件系统和网络栈 | Linux/BSP、SoM + 载板、PMIC/散热 | 明确接受较高功耗、体积、启动时间和系统集成成本 |

### 2.4 验证方法

#### 2.4.1 测试条件

- 输入：4 kHz、单声道、16-bit PCM；2 s 窗；0.5 窗/s；目标板实际 INT8 运行格式。
- 单板基线：记录开发板版本、芯片版本、时钟配置、无线模组、屏幕型号和亮度、
  电源轨、固件 commit 和推理框架版本。
- 推理：连续 1,000 次；记录平均、P95、最大时延；记录峰值 heap、碎片和模型
  Flash 占用。
- 并发：推理 + BLE 连续接收 + Wi-Fi 上传/同步 + 显示刷新 + 音频回放，连续
  5 分钟；记录 BLE 丢帧/断连、显示帧率、Wi-Fi 阻塞和看门狗复位。
- 功耗：用功率分析仪或电流探头分别记录待机、BLE 接收、Wi-Fi 上传、显示、
  推理和并发场景的平均/峰值电流。
- 模型质量：完整 CirCor 患者级测试；记录 INT8 相对 FP32 的 AUROC、敏感度、
  特异度和 balanced accuracy。
- 边缘部署：断开手机、服务器和外部网络后，设备仍能完成采样、推理、显示和
  本地缓存；不得依赖外部设备补充推理。

#### 2.4.2 失败判据

- 任一必需功能无法同时工作：BLE central、Wi-Fi station/SoftAP、显示、音频
  回放、本地缓存、电池供电。
- 模型文件占可用 Flash >=50%。
- 峰值 RAM 占可用内存 >=70%。
- P95 推理时延超过已确认显示更新周期的 50%。显示周期未冻结前，暂以
  10 fps / 100 ms 对应 P95 <=50 ms 作为候选门槛（E4，待组会确认）。
- 推理期间 BLE 持续丢帧、断连，或 Wi-Fi 上传阻塞推理/显示。
- 系统功耗或温度超过已确认电池/热预算；预算未定义前不能判定通过。
- 完整患者级 AUROC <0.70；balanced accuracy <0.65；INT8 相对 FP32 的
  AUROC 下降 >0.03。

#### 2.4.3 回退与改选触发

- A 仅因计算、RAM 或 MIPI 显示不足，且 B 的功耗/成本可接受：切换到
  **B ESP32-P4 + C6**。
- A/B 被真实模型算子或吞吐证明不足，且 NPU 实测收益超过集成成本：启动
  **C STM32N6 + 独立无线**。
- AI/GUI 集成成为主瓶颈，且产品能接受更高功耗、体积和启动时间：评估
  **D Linux SoC/SBC**。
- 项目进度或成本无法承受扩展任务，或所有边缘候选均未达门槛：回退到
  **当前边缘二分类模型**，只做采集、显示、回放、缓存和上传；不得把推理
  外移到手机、服务器或云端。
- 任何主机平台切换都不得改变 AUD1/LKA1，不得改变探头侧接口和黄金向量。

### 2.5 当前结论

ADR-006 v2 仍为“候选”。现有模型预算足够小，支持优先验证 ESP32-S3；但
模型文件大小和 MACs 不能证明目标板 P95、峰值 RAM、功耗或 BLE/Wi-Fi/显示
并发一定通过。只有完成 2.4 的目标板测试后，才能把候选 A 升级为“已确认”；
否则保持候选，并保留原 ADR-006 记录。
