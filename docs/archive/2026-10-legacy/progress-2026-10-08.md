# 2026-10-07 至 2026-10-08 进度摘要

## 1. 架构与接口决策

- 确认主机和手机可以使用 Wi-Fi 连接，链路 B 从“蓝牙限定”调整为 Wi-Fi 优先。
- 链路 A 仍保留 BLE 5.0 GATT 候选方案，优先 2M PHY；ESP-NOW 只作为两端均为
  Espressif 平台时的原型备选。

- 建立工程决策规范、ADR 登记表和组会方案对比页模板。
- 主机计算平台登记为 ADR-006，必须等 AI 模型资源预算和目标板实测后冻结。

## 2. 协议与软件

- 完成 `AUD1` 音频帧的 C 实现和 Node 参考实现。

- 增加 C/Node 黄金测试向量、丢包/乱序测试、软件端到端模拟器和 GitHub Actions 入口。

## 3. AI 基线与数据

- 建立 CirCor 1.0.3 数据准备、子集下载、完整包分块续传、患者级划分和验证脚本。
- 实现 NumPy 逻辑回归对照基线和 PyTorch 小型 1D CNN。
- 完成患者级分层 5 折交叉验证，比较 `all` 与 `annotated` 两种窗口策略。
- 完整公开训练集：942 名受试者、3163 条录音；排除 `Unknown` 后为 874 名受试者、
  3007 条录音。

模型资源候选值：

- 小型 1D CNN 参数量：41,105。
- INT8 权重估算：约 40.1 KiB。
- ONNX INT8 文件：约 68.7 KiB。
- 单窗口 MACs：5,722,944。
- PC ONNX INT8 平均推理时间约 0.12 ms，P95 约 0.98 ms。
- 目标板峰值 RAM、P95 时延、电流、显示和无线并发：待实测。

限制：完整交叉验证仍是本机公开数据实验，不等价于目标板部署；模型不能据此
冻结主机芯片，也不能作为临床结论。
