# 311 FYP 采购与报销流程

本目录归档学校提供的 311 FYP 采购、报销和开票资料，并把实际操作步骤整理成
便于检索和核对的清单。流程要求以学校原始通知和实验室管理员的最新通知为准。

## 归档文件

- [311 FYP 采购与报销流程 SOP（公开归档版）](source/311-fyp-purchase-reimbursement-sop-redacted.pdf)
- [附件 1：单位开票资料](source/invoice-issuer-information.pdf)

`311 FYP 采购与报销流程 SOP` 原件第 2、3 页包含示例学生姓名和学号，第 5 页
包含示例发票经办人姓名。由于本仓库是公开仓库，本目录只归档脱敏后的图像版
PDF；黑色遮挡块表示已移除的信息。原始未脱敏文件仍保留在本地，不上传 GitHub。

`附件 1` 含单位名称、纳税人识别号、地址、电话、开户行和银行账号。它们是
学校开票所需的组织信息，但公开后无法从 Git 历史中撤回，使用和转发时仍应注意。

## 归档方式选择

| 方案 | 优点 | 风险与代价 | 结论 |
| --- | --- | --- | --- |
| 原样上传两份 PDF | 版式、文字层和表格最完整 | 公开仓库会泄露示例学生姓名和学号，且难以撤回 | 不采用 |
| 只上传 Markdown 摘要 | 无个人身份信息，便于检索 | 丢失原流程图、表格和发票示例版式 | 不作为唯一方案 |
| 上传脱敏 PDF + Markdown 摘要 | 保留可视版式和操作细节，同时移除个人身份信息 | PDF 转为图像版，不能直接搜索正文；需维护摘要 | 当前采用 |

仓库公开状态于 2026-10-17 通过 GitHub API 核对。脱敏检查方法为逐页渲染 PDF，
人工核对姓名、学号和经办人栏，并确认遮挡区域未覆盖关键流程文字。

## 一页流程

1. **采购前预审批**：填写采购申请表格，说明用途和预计金额，发送给 PI 审批。
2. **审批后采购**：按 PI 意见修改表格，保留最终同意邮件，并采购获批物品。
3. **个人交材料**：把电子档和纸质档交给本组协调员，也就是导师组小组长。
4. **协调员汇总**：核对发票、订单和金额，填写组长报销表格并统一提交。
5. **实验室管理员提交财务**：财务完成报销后，款项发给协调员，再分发给组员。

## 基本规则

- 311 Program ECE Project 学生可报销与毕业设计相关的耗材、资料等费用。
- 每个学生每学年固定额度为 **RMB 1500**。
- 报销必须具备抬头正确的发票和 PI 同意邮件。
- 收据不能代替发票。
- 发票抬头必须与单位开票资料完全一致，个人抬头或自行增加括号内容不能报销。
- 化学品或其他有安全风险的物品，采购前必须先联系实验室管理员，不允许自行购买，
  自费购买也不行。
- 有安全风险的仪器或小型设备，采购前须报备并提交风险评估表。

## 组长报销表格填写

表格包含三个分表：

- `报销单`：只需填写此表，其他分表自动生成。
- `Summary`：自动生成，填写后检查汇总金额。
- `Class Roster`：包含学生姓名、学号和组号，首次使用时核对。

每次应从原始模板开始填写，不要直接在上个月文件上续改。

## 发票整理

### 非 A4 发票

- 按发票顺序，用固体胶粘在空白 A4 纸上，不要用订书机。
- 从横向 A4 纸最左侧开始粘，只粘发票的邮票孔部分。
- 专用发票只粘发票联；抵扣联不要粘，用回形针随附固定。
- 专用发票需要提交发票联和抵扣联两张。

### 电子发票

- 每张统一打印成 A4 大小。
- 不需要粘贴，按顺序排好即可。
- 普通发票通常只需名称和纳税人识别号；电子普通发票可黑白打印，
  一张纸打印一张发票。

### 报销单对应关系

- 先按顺序粘好发票，再填写 `报销单`，避免纸质发票和电子发票顺序混在一起。
- 一张发票占一行，并在发票右上角写上发票序号，即 `Reimbursement NO.` 后两位。
- `Description(s) of item(s)` 要详细填写实际购买的物品名称。
- `Category` 选择正确分类，`Sub-Total(¥)` 填写税后金额。
- 订单实付金额与发票金额不一致时，以实际支付金额报销，并在纸质订单上用铅笔标记。

## 时间与额度限制

- 研究院只受理当年 1 月 1 日至 12 月 31 日内产生的票据和付款申请，逾期不受理。
- 与毕业设计相关的票据付款日期，必须从毕业设计开始后到 CA2 整体答辩首日之前。
- `CA2 整体答辩首日`按全体答辩安排计算，不是个人答辩日期。
- 晚于整体答辩首日的报销单据不予受理。
- 特殊情况应及时联系实验室管理员，不要等到截止日期后再处理。

## 项目结束时的物品处理

- PI 要求下届学生继续使用的作品或物品，项目结束后要交回实验室统一保管。
- 交接时需要按实验室要求办理登记手续。

## 最短检查顺序

采购前看 `PI 审批`，付款后看 `发票抬头 + 税号 + 实付金额`，交材料前看
`电子档压缩包 + 纸质档回形针 + 组长表格金额`，提交前再看 `4/18 时间点`和
`CA2 整体答辩首日`。任何一项不确定时，先联系协调员或实验室管理员确认。
