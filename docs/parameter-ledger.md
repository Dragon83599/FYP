# 参数台账：每一个参数的取值与出处（2026-10-29）

> 目的：**任何参数都能追到"哪来的"**。三类来源：
> - **【文献 N】**：第 N 篇笔记的原文有明确数字/原话
> - **【ADR-xxx】**：本项目决策记录（可能基于文献推理或工程约束）
> - **【E4】**：工程判断，文献没说，必须在论文里如实标注
>
> 若某参数你找不到【文献】，说明它本来就没有文献依据——**不要假装有**。

> **配套文档**：每个参数的"一句话理由"见 `docs/parameter-rationale.md`（20 张理由卡，含"取别的会怎样"与"怎么验证"）。

## 三条要写进论文的"诚实声明"

1. **录音级聚合（soft voting）无文献先例**——写"本文采用"，不写"文献常用"。
2. **帧长 25 ms / 帧移 10 ms 是工程选择**——语料里无人使用；26 用 0.2 s 帧。
3. **端点检测的阈值（噪声底×3）未做敏感性分析**——若要更稳，可补一组阈值扫描。
