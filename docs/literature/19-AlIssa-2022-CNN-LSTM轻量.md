## 数据

- **主数据集：Yaseen 的 1,000 条**（5 类各 200，8 kHz 单声道，约 3 s）
- **增强后：每类 3,000 条，共 15,000 条**（×15）
  - 增强手段：**时间拉伸、时间平移、加噪、音量控制**
- 第二数据集：**PhysioNet/CinC2016**，2,725 正常 + 816 异常（二分类）
- 划分：**10 折交叉验证**
- 患者 ID：无

## 方法

- 预处理：**只做降采样**——时域输入裁成 8,000 点，频域输入取 **1,000 点 FFT**；作者强调**不做滤波、去噪、MODWT**（对比 Alkhodari 的做法）
- 模型（Table 4）：

| 层 | 配置 |
| --- | --- |
| Conv1–4 | 滤波器 **48 / 32 / 16 / 64**，核长 **3**，每层 BN + ReLU |
| MaxPool | 核 2、步长 2（共 3 次）|
| Flatten | — |
| **LSTM 1 / 2** | **64 / 32** 个隐藏单元 |
| 输出 | 全连接 5 类 + softmax |

- 训练：lr **0.001（时域）/ 0.0001（频域）**，最多 **100 epochs**，10 折
- 推理耗时（Table 14，桌面 CPU）：CNN-LSTM 约 **1.63–1.86 ms**/样本；FFT 约 1.0 ms

## 与我的 FYP 的关系

- 可借鉴：
  1. **时域 vs 频域输入的直接对照**（98.48 vs 95.40）——同一模型、同一数据，只换输入表示，这是很干净的一组对照，可当"原始波形优于 FFT 幅度"的旁证；
  2. **四种音频增强**（时间拉伸、时间平移、加噪、音量）都很便宜，可以搬到 A3；
  3. **只做降采样、不做滤波**也能到 98%+——与我们的 20–1000 Hz 带通形成对照，值得在 A1/A3 里试一次"不去噪"的对照。
- **严重问题（必须知道）**：
  - **增强发生在划分之前**：先把 1,000 条扩成 15,000 条，再做 10 折 → **同一段原始录音的多个增强副本很可能分散到训练折和测试折**，这是**数据泄漏**，会显著抬高准确率。99.87% 因此不可信。
  - **仅 LSTM 只有 50.70%**（五分类随机水平）——说明增益几乎全来自 CNN，"CNN-LSTM 混合更优"的结论缺乏支撑。
  - **没有报参数量**：标题说 "lightweight"，但全文没有参数数字。
  - 按层表**粗算**（E4 估算）：Flatten 后约 64 通道 × 1,000 长度 = 64,000 维输入 LSTM(64)，仅这一层就可能上千万参数——**"lightweight" 很可能不成立**，需作者给数或自行复现核对。
- 不能用的部分：
  - **不能引 99.87%** 作为"五分类可达到的水平"（增强泄漏）；
  - 不能引它证明"CNN+LSTM 优于纯 CNN"（消融不支持）；
  - 不能引它说"轻量"（无参数量）。
