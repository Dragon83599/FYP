## 数据与噪声构造（本节最值得学）

- 主数据：**GitHub PCG（= Yaseen）**，五分类，切成 **3.5 s** 帧
- **噪声构造**：把心音（HS）与**肺音（LS）按指定 SNR 混合**，生成"含噪心音数据集"
- 这样做的好处：噪声是**真实生理噪声**（肺音），不是高斯白噪；且 SNR 可控，可画"准确率–SNR"曲线

## 方法

- 四种时频变换：**CQT、CWT、STFT、MFCC** → 统一生成 **224×224** 的二维图
- 基线：**VGG16**；对比：**MobileNetV2**
- 提出 **NRC-Net** 四段结构：
  1. **SFEB**（Spatial Feature Extractor Block）
  2. **HAB**（Holistic Attention Block）
  3. **TFEB**（Temporal Feature Extractor Block）
  4. **TCB**（Terminal Classification Block，softmax 五类）
- 训练：10 折 CV，batch 16，lr 1e-4，60 epochs，Adam，交叉熵

## 结果（原文数字）

| 条件 | 结果 |
| --- | --- |
| **干净数据**（CWT + NRC-Net）| **99.7%** |
| **含噪数据**（CWT + NRC-Net）| **97.4%** |
| 含噪 VGG16（CWT）| 95.69% |
| 结论 | **CWT 是最优变换**，比第二名 CQT 高 1.95% |

### 为什么用"肺音"造噪：干扰的物理来源（2026-10-28 补充）

**肺音一定会混进心音录音里**，原因不是电路噪声，而是生理传导：

```
肺部气流湍流 → 肺组织 → 胸壁 → 皮肤 → 麦克风
心脏瓣膜关闭 → 胸腔 → 胸壁 → 皮肤 → 同一个麦克风
```

心音能到达体表所依赖的传导路径，同时也是肺音到达体表的路径，因此同一只麦克风无法只接收心音而不接收肺音。

**频率上两者重叠**：

| 声源 | 主要频段 | 时间特性 |
| --- | --- | --- |
| S1/S2 | 20–150 Hz | 瞬态 |
| 杂音 | 100–600 Hz | 持续 |
| **呼吸音** | **100–1000 Hz** | 持续、宽频 |

重叠区 **100–600 Hz** 正是杂音所在频段。

**两个后果**：

1. **带通去不掉**：我们的 20–1000 Hz 会把肺音完整保留；若砍到 150 Hz 以下，又会削掉 AS 杂音（见 23）；
2. **它比白噪声更"像信号"**：肺音有结构、有呼吸节律，模型可能把它当特征学进去——这正是本文用**真实肺音**而非只用 AWGN 的原因。

**四种缓解手段**：

| 手段 | 代价 |
| --- | --- |
| 憋气录音（屏息 3–5 s）| 需患者配合 |
| 质量门（ADR-028）| 覆盖率下降 |
| **训练时按 SNR 混肺音**（本文做法）| 需肺音数据源 |
| 呼吸期门控（只在呼气末取样）| 额外算法 |

→ 这也是"Yaseen 数据集内 99% → 真实场景 80 多"的主要来源之一：CD 录音相对干净，真实听诊中肺音持续存在。

### 第 2 站：噪声怎么造（本文最值得学的部分）

```
干净心音（3.5 s 帧）
   ├─ + 肺音，按 0/5/10/15 dB
   └─ + 高斯白噪声（AWGN），按 0/5/10/15 dB
        ↓
   含噪心音集（每个 SNR 一套）
```

**为什么这比"加高斯白噪"好**：肺音是**真实生理干扰**（听诊时最常见），而且 SNR 可控 → 能画"准确率–SNR"曲线，看出模型在哪个噪声水平崩溃。

### 第 5 站：结果的关键数字

| 条件 | VGG16 | NRC-Net |
| --- | --- | --- |
| 干净 | 99.5% | **99.7%** |
| **含噪（平均）** | **95.69%** | **97.4%** |

**逐 SNR（四种变换的对比列）**：15 dB → 约 96%；10 dB → 约 95%；更低 SNR 掉得更快。

**结论**：**CWT 是最优变换**（比第二名 CQT 高 1.95%）。

### 与我们的关系

- **可搬**：噪声构造 + SNR 曲线的实验设计；
- **不可搬**：224×224 二维图 + VGG 级 CNN，与端侧目标相反；
- **注意**：它的"平均 97.4%"是**四个 SNR 的平均**，不是单一条件；引用时必须写清。
