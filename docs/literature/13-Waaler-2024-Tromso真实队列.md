## 数据

- 队列：**Tromsø7 研究**（挪威，2015–2016），全人群抽样 + 超声心动图
- 规模：2,132 人同时有超声与心音 → 最终 **2,124 人、8,496 条录音（1,416 分钟）**
- 采集：听诊器管内装麦克风（Sennheiser MKE 2-EW，Littmann Classic II 管，距胸件 10 cm），无线传输，**10 s、44.1 kHz、16-bit、单声道**
- 位置：**4 个听诊区**（主动脉、肺动脉、三尖瓣、二尖瓣）
- 标注：**2 名全科医生**按 Levine 分级 0–6 标杂音（看频谱图，**对超声结果盲**）；先共同标 400 条达成一致
- 金标准：GE Vivid E9 超声；AS/MS 0–3 级，AR/MR 0–4 级；**AS 用平均压差 AVPGmean（15/20/40 mmHg）**
- 划分：**按受试者 ID 划分**——先留出 **212 人 holdout**，其余 1,912 人做 **8 折 CV**
- 患者 ID：**有，且严格按人划分**（这是它比 01/03/11/12 都干净的地方）

## 方法

- 预处理：去尖峰（按 Schmidt 2009）→ 降采到 **2,205 Hz** → 用**改良 Springer 分割**找 S1，切成 **6 个 50% 重叠、每块 4 个心动周期**的段
- 特征：**13 维 MFCC**（Hanning 窗），重采样成 **13×200** 矩阵，**减均值除标准差**
- 模型：**两层 LSTM（各 50 单元）→ 全连接 30 → 回归层**，输出**杂音等级**（0–6），6 段取**中位数**
- 训练：lr 0.002，每 5 epoch 减半；对杂音≥1 的样本重采样到约 **1:1**
- **两级设计**：先预测杂音等级 → 再用线性回归把杂音等级映射到 AS（因 AS 病例太少，直接分类会过拟合）；超参调节只看**杂音预测**，不看 VHD
- 临床变量：年龄、性别、BMI、心率、血压、症状等，用逻辑回归与心音预测融合

## 结果（原文数字）

| 目标 | 指标 |
| --- | --- |
| **AS（≥1 级）** | 敏感度 **90.9%**、特异度 **94.5%**、**AUC 0.979**（0.963–0.995）|
| AS ≥ 2 级（至少中度）| **AUC 0.993**（0.989–0.997）|
| **AR（≥ 中度）** | **AUC 0.634**（0.565–0.703）|
| **MR（≥ 中度）** | **AUC 0.549**（0.506–0.593）|
| AR / MR + 临床变量 | 0.766 / 0.677 |
| 有症状的 AR / MR | 0.756 / 0.711 |
| 联合筛查（有症状反流 或 任一狭窄）| **AUC 0.86**；**97.7% 的 AS（n=44）** 与 **全部 12 例 MS** 被检出 |

- 明确结论：**AS 检测很好，AR/MR 从心音基本测不出**；加入临床变量才明显改善。

### 2026-10-26 你的疑问：p5 为什么又提到 RNN

> 为什么第五页的Combining clinical variables and heart sound predictions这一段又提到了RNN模型

**逐字保留，未改写。** 因为这一段是**两级模型里的第二级**，它的输入之一就是第一级 RNN 的输出。

原文：

> `we created, for each VHD, a multivariate logistic regression model that takes as input a set of clinical variables as well as the VHD prediction by RNN models to form a predictor that incorporates both sources of input`

结构如下：

```
录音 ──► RNN（第一级）──► 预测的"杂音等级"（0–6 的一个数）
                              │
临床变量（年龄/性别/气促/吸烟/心率…）──┤
                              ▼
             逻辑回归（第二级）──► 该 VHD 的概率
```

**关键点**：第二级用的不是 RNN 的"深度特征"，而是它输出的**一个标量（杂音等级）**。所以：

- 好处：可解释、参数少、不会过拟合；
- 代价：把 RNN 学到的信息压成了一个数，信息损失很大。

**几个具体设计（p5）**

| 设计 | 内容 |
| --- | --- |
| 杂音等级怎么聚合 | AS 用"多位置模型"的输出；MR 用**二尖瓣位置**的等级；AR 与 MS 用四个录音里的**最高等级** |
| 交互项 | 加入"性别 × 杂音等级"，检验同样的杂音在男女身上的风险是否不同 |
| 防泄漏 | `The RNN predictions were collected from the validation sets during cross-validations`——用的是**折外预测**，不是训练集上的预测 |

⚠️ 原文这句 `the MR model used the grade predicted from the mitral position, and the MR and MS models used the highest murmur grade` 里 **MR 出现了两次**，按上下文第二个应为 **AR**——疑为笔误，记入待查证。

### 2026-10-26 你的理解与疑问（LSTM/RNN、多标签、误判）

> 这篇文特征提取就还是MFCC，然后模型是LSTM（之前好像没接触过），因为AS病例太少所以采用了RNN+逻辑回归的两级设计（模型到底是什么LSTM还是RNN），但是这个任务的分类是多标签二分类，我不太理解是只区分AR和MR的意思吗，那剩下两个疾病会不会造成误判

**逐字保留，未改写。** 逐条回应：

**（1）特征：MFCC，对。** 13 维 MFCC，重采样成 13×200 后标准化。

**（2）"到底是 LSTM 还是 RNN"：同一个东西的两个层级。**

- **RNN 是家族名**（循环神经网络）；**LSTM 是其中一种单元**。
- 原文 Abstract/Methods 说 "recurrent neural network (RNN)"，具体实现在 p4：**两层 LSTM（各 50 单元）+ 全连接 30**。
- 所以看到 "RNN" 就理解为"这篇用的是 LSTM 实现"即可。

**（3）为什么要两级：不是因为 AS 一个病，而是所有 VHD 病例都太少。**

| 病 | 例数（占队列）|
| --- | --- |
| AS ≥ 1 | **45（2.1%）** |
| AR ≥ 3 | 150（7.1%）|
| MR ≥ 3 | 292（13.7%）|
| MS ≥ 1 | **13（0.6%）** |

原文：VHD 病例太少，"没有足够统计功效同时开发模型和估计性能"。所以：

1. 先训练 RNN 预测**杂音等级（0–6）**——这个标签更密、更容易学；
2. 再用**逻辑回归**把"杂音等级 + 临床变量"映射到各个 VHD。

AS 还多做了一步：因为只有 45 例，直接分类会过拟合，所以**回归 AVPGmean（连续值）**，再按阈值判 AS。

**（4）"多标签二分类"：不是只分 AR 和 MR，而是四个病各一个二分类。**

| 标签 | 定义 |
| --- | --- |
| AS ≥ 1 / ≥ 2 | 主动脉狭窄（轻/中重度）|
| AR ≥ 3 / ≥ 4 | 主动脉反流（中/重度）|
| MR ≥ 3 / ≥ 4 | 二尖瓣反流 |
| MS ≥ 1 | 二尖瓣狭窄 |

- **"多标签"= 一个人可以同时有多个病**，标签之间不互斥；
- 所以**不是**"只区分 AR 和 MR"，四个病都有各自的模型和 AUC；
- 我们的五分类是**互斥单标签**（N/AS/MS/MR/MVP 选一个），和它的设定根本不同，**数字不能横比**。

**（5）"剩下两个病会不会造成误判"：会，而且作者自己报了。**

原文（MS 那一段）：

- `None of the MS recordings had diastolic murmurs, despite the characteristic MS murmur occurring during diastole.`——**没有一条 MS 录音出现舒张期杂音**；
- `Seven of the total 13 cases (53.9%) of MS also had AS, indicating a considerable disease overlap.`——**13 例 MS 里有 7 例同时有 AS**；
- 被检出的 10 例 MS 里，4 例有 AS，3 例没有其他 VHD。

也就是说：**MS 的"高 AUC 0.922"很可能部分来自共存的 AS 杂音**，而不是模型真的听出了二尖瓣狭窄。这正是多标签数据的固有问题——**共存病会互相"借证据"**。

### 2026-10-26 你的追问：同一个人得两种病，五分类会不会漏判

> 那有没有可能同一个人得两种病，那我的五类不就会少判断出一种病吗

**逐字保留，未改写。** 会，而且这是**单标签任务的固有缺陷**，不是模型 bug。

**（1）机制上必然漏**

五分类用 softmax，输出的是一个概率分布——**五个类互相竞争，只能选一个**。如果一段录音里同时有 AS 和 MR，模型只能挑一个最像的，另一个**从结构上就不可能被输出**。

**（2）但在 Yaseen 这份数据里，"漏判"无从谈起**

Yaseen 的每条录音**只标了一个类**（N/AS/MS/MR/MVP）。所以：

- 相对**数据标签**，模型没有"漏"——标签本来就是单标签；
- 真正的问题是**数据构建时怎么处理合并病变**：Yaseen 论文**没说**是否排除了同时有两种病的人。→ 记入待查证。
- 如果原始数据里本来就没有"合并病变"的样本，模型**连见都没见过**，更不能指望它识别。

**（3）临床上合并病变很常见——文献里到处是证据**

| 文献 | 证据 |
| --- | --- |
| **Waaler（本篇）** | 13 例 MS 里 **7 例同时有 AS**（53.9%）；且"没有一条 MS 录音有舒张期杂音" |
| Chorba（15） | 明确"允许合并 VHD"，但要求**其他瓣膜的严重度不超过目标瓣膜** |
| Makimoto（16） | 因为 AS 与 MR 的收缩期杂音容易混，建交叉验证集时**刻意平衡 MR 例数** |
| Shiraga（14） | 干脆按病种**分开建模**（AS、MR、LVD 各自一个模型） |

**（4）我们能做什么、不能做什么**

- **不能**：把五分类模型的输出"拆成多标签"——softmax 天然互斥，拆不出来；数据也没有多标签标注，无法训练 sigmoid 多头。
- **能**：在论文的 limitations 里明确写"本任务是**单标签基准**，不适用于合并病变的临床筛查"；未来工作可以提"多标签 sigmoid 头 + 合并病变标注"。
- **答辩时的标准答法**：不是"我们的模型能诊断"，而是"我们在**单标签、互斥五类**的基准上比较特征与模型，合并病变不在本研究范围内"。

### 2026-10-26 你的追问：softmax 下 AS、MR 都高，能不能判合并病变

> 假如最后输出AS、MR的的概率都很高可不可以判断为合并病变

**逐字保留，未改写。** 不能。三个理由：

**（1）softmax 下"两个都高"在数学上最多各约 50%**

softmax 的概率和恒为 1。假设 AS、MR 的 logit 都是 2、其余为 0：

| 类 | logit | 概率 |
| --- | --- | --- |
| AS | 2 | **0.40** |
| MR | 2 | **0.40** |
| N / MS / MVP | 0 | 各 0.07 |

"两个都高"实际是"各 40%"，而且**它们加起来被 1 封顶**。所以它表达的是**模型分不清**，不是"两个病都存在"。

**（2）模型从没见过"两个都对"的样本**

训练标签是 one-hot（每条只有一个 1）。模型学到的映射是"在五个类里选一个"，**没有任何训练信号告诉它"同时成立"长什么样**。所以 AS、MR 同时高，最可能的解释是**两类杂音在声学上相似**（收缩期杂音重叠），而不是合并病变。

**（3）softmax 输出不是"患病概率"**

它是"**在恰好有一个类为真的前提下**，是这一类的概率"。前提本身就不成立（合并病变时有两个为真），所以数值不能当合并病变的证据。

**什么才算证据**

1. **换结构**：多标签 sigmoid 头（每类独立 0/1）+ 二元交叉熵；
2. **换数据**：有超声确认的合并病例，且合并组合的样本量足够；
3. **换评价**：每标签 AUC、Hamming loss、subset accuracy。

**一个折中（可以做，但只能叫"不确定性"）**

把"top-2 概率接近"当作**模型不确定**的指标报告（比如 top-2 差 < 0.1 的比例），**不能**叫合并病变判断。若要做，需要一个验证：在有合并病变标注的数据上，看"top-2 接近"能否预测合并（ROC）——我们没有这种数据，所以只能停在"不确定性"。

## 还能学到的 7 个做法（2026-10-26 补）

除了"按患者划分"和"两级设计"，这篇在**方法学细节**上还有不少可直接抄的。

| # | 他们的做法 | 为什么 | 我们怎么用 |
| --- | --- | --- | --- |
| 1 | **用 8 折而不是 5 折**（`we opted to rely primarily on eightfold CV`）| VHD 病例少，折数越多，每折训练集越大 | 我们 1,000 条、5 类均衡，5 折可以；但若某类样本少，改 8 折或重复分层 5 折 |
| 2 | **先留 holdout，再开发**（212 人，约 10%）| 防止"开发时已经见过测试数据" | 我们的对应做法：五折之外再留一个 holdout，只在最后测一次 |
| 3 | **调参只看"杂音"，不看"VHD"** | 目标病太少，按 VHD 调参会过拟合 | 我们没有代理任务，但可以固定"按 macro F1 调参"，不按某类 |
| 4 | **架构尽量沿用前作**（`most decisions ... were based on a previous study`）| 减少"针对开发集调结构"的自由度 | 我们的 A1–A5 已经是"照文献配置"，这一条基本满足 |
| 5 | **折外预测合并算 AUC**（`calculated for all CV predictions jointly since some CV validation sets had 0 cases`）| 稀有类在某些折里一个阳性都没有，AUC 无定义 | 我们做 bootstrap CI 时同样会遇到；用 **pooled out-of-fold predictions** |
| 6 | **按严重度分层报告**（AS≥1 0.979、AS≥2 0.995；MR≥3 0.558）| 一个数字会掩盖"轻度难、重度易" | 我们只有五类、没有严重度标签 → 做不到，但要说明"Yaseen 无严重度信息" |
| 7 | **噪声的工程规则**：训练只用两位标注者都同意"不吵"的录音；多录音预测时，噪声录音记 **grade 0** | 简单、可复现、不需要额外模型 | 我们若做端点检测/质量筛，可以借用"质量不合格直接排除或记零"的思路 |

**还有两条偏"写作"的**

- **标注流程可复制**：先由两名全科医生**共同标 400 条达成共识**，之后定期校准，且**对超声结果盲**。我们将来若要自标小数据集，这是模板。
- **方法描述足够细**：去尖峰（按 Schmidt 2009）→ 降采到 **2,205 Hz** → 切 **6 段 × 4 个心动周期** → **13 维 MFCC** → resize 成 **13×200** → 标准化 → 2 层 LSTM(50) + FC(30)。每一步都能复现，这正是我们 methods 章该有的密度。

**不要照搬的**

- 44.1 kHz、听诊器管内麦克风、10 s × 4 个位置——这是我们设备做不到的；
- 多标签任务设定——我们是互斥五类。

## 与我的 FYP 的关系

- 可借鉴（方法学上最值得抄的一篇）：
  1. **按患者 ID 划分 + 预先留出 holdout**，且**超参只按"杂音"调、不按"VHD"调**——这是防止"用测试集选模型"的标准做法，正好补上 11/12 的漏洞；
  2. **两级设计**（杂音 → VHD）而不是直接五分类：因为 VHD 病例太少；这和我们 ADR-021 讨论过的"二分类门 + 四分类"是同一思路（虽然我们最终选了候选 0）；
  3. **多听诊位融合**：4 个位置各出预测，再回归融合，比单位置好。
- 可改进 / 需要知道：
  - 它是 **AS/AR/MR/MS 的多标签二分类**，不是 N/AS/MS/MR/MVP 五分类；**数据是真实人群，没法和 Yaseen 的数字横比**；
  - 采样 44.1 kHz、麦克风装在听诊器管里，和我们的 8 kHz 数据不是一回事。
- **给我们最重要的对照**：Yaseen 上各法报 97–99%，而真实人群里 **AR 0.634、MR 0.549**——这再次说明"数据集内高分"和"临床可用"是两件事（与 04 的 Alkhodari 87.31%、11 的 MHSMD 96.79% 同向）。
- **一个有用的工程事实（E4 估算，非原文）**：两层 LSTM(50) + FC(30) 参数量约 **3.5 万**（LSTM1 12.8k + LSTM2 20.2k + FC 1.5k），INT8 约 35 KB——**落在我们 ≤150k 参数的预算内**。也就是说"小模型 + 低采样率 + 两级设计"在端侧是可行的，代价是精度上限（AR/MR 很差）。

## 待查证

- "改良 Springer 分割"的具体修改（原文放在补充材料）。
