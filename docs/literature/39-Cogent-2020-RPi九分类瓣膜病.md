# 39 · 2020 · 树莓派上的 9 类瓣膜病诊断系统

> 阅读深度：**摘要级**（OpenAlex 摘要；全文未取）。
> **价值：SBC 层级里目前唯一做"多类瓣膜病"（9 类）的作品，与我们任务最接近。**

## 引用

- 标题：A portable Raspberry Pi-based system for diagnosis of heart valve diseases using automatic segmentation and artificial neural networks
- 期刊：**Cogent Engineering 2020**
- DOI：10.1080/23311916.2020.1856757

## 它做了什么（摘要）

| 项 | 内容 |
| --- | --- |
| 任务 | **9 类**：8 种瓣膜病 + 正常 |
| 方法 | **自动分割 + 人工神经网络（ANN）** |
| 平台 | **Raspberry Pi + 触摸屏**；自带 PCG 采集模块 |
| 产出 | 一套完整便携诊断硬件 |

## 与我的 FYP 的关系

**能用的**：
1. 证明 **SBC 上做多类瓣膜病分类是可行的**（不只是二分类）；
2. 它的"分割 + ANN"路线与我们的 A3（不分割 + 1D CNN）形成对照——**又多一个"分割 vs 不分割"的现实案例**；
3. 它是 2020 年的工作，**9 类**比我们 5 类更难，可作为"任务难度"参照。

**注意**：
- 摘要没给出端上时延与内存；**不能引用其性能**；
- 类别定义（哪 8 种病）需回原文确认，与我们的 AS/MS/MR/MVP 不一定对齐。
