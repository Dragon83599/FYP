## 数据

- **主数据集：Yaseen 的 1,000 条**（5 类）——但注意：这篇把 Yaseen 写成 **AR**（主动脉反流），实际是 **AS**（主动脉狭窄）。原文两处都这么写，**是它的笔误**。
- 预处理：**降采到 1 kHz** → **2 s 不重叠切窗**（2,000 点）→ 幅度缩放到 [-1, 1]
  - 理由：杂音频率 200–410 Hz，1 kHz 足够
  - Yaseen 原始长度不一 → 长的裁、短的补零到 2 s
- **无标签数据（SSL 用）**：PhysioNet/CinC2016 里 4 个子库（Aalborg、Haute Alsace、大连理工、Shiraz）的"可解释"录音，**丢掉原标签**当无监督数据
- 外部验证：**PASCAL**（2011 挑战，手机录制），84/84 训练、34 测试
- 划分：**10 折交叉验证**（Yaseen）；PASCAL 是固定 train/test

## 方法

### 1. 轻量 1D CNN（20,193 参数）

- 输入 **2,000 点**（2 s @ 1 kHz）
- **3 组 Conv + MaxPool**：卷积核 **20**、滤波器 **16 / 8 / 4**；池化核 **4**
- **FC 128** → **5 类 softmax**
- 激活 **tanh**；损失交叉熵；优化器 **Adam**
- 设计原则（原文）：不用残差块、用小卷积核、尽早池化以压缩 FC 输入

### 2. 自监督预训练（SSL）

- 对无标签 PCG 做 **6 种变换**，每种以 50% 概率施加：
  **加高斯噪声（scale 0.2）、幅度缩放 80%、幅值翻转、时间翻转、分段随机重排（10 段）、分段拉伸/压缩（10 段）**
- 每个样本得到 **6 个二值伪标签**（是否被施加该变换）
- 上游网络 = 同样的 3 组卷积 + 6 个分支（每个分支 2 层 FC），**多任务二分类**
- 收敛后**只把第一层卷积的参数迁移**到下游模型，并**冻结**
- 下游再用 Yaseen 的标签做 10 折训练

### 3. 部署形态

- Keras → **TensorFlow.js** → **PWA（渐进式 Web 应用）**，在手机浏览器里跑（WebGL 后端）
- 支持**端上微调**和端上推理

## 2.3 节（自监督）白话版（2026-10-26 应你要求）

### 一句话

**没有标签，就自己出题**：把无标签的心音"弄坏"一下，让网络猜"你动了哪里"。猜得出来，说明它已经懂了心音长什么样。

### 六种"弄坏"的方式

| 变换 | 具体做法 | 像现实里的什么 |
| --- | --- | --- |
| 加噪 | 加 σ=0.2 的高斯噪声 | 诊室环境噪声 |
| 缩放 | 幅度乘 0.8 | 录音音量大小不同 |
| 幅值翻转 | $x \to -x$（上下翻）| 信号极性相反 |
| 时间翻转 | 前后倒放 | 录音从心动周期中间开始 |
| 置换 | 切成 10 段、**打乱顺序**接回去 | 时间结构被破坏 |
| 拉伸 | 切成 10 段、**每段各自伸缩** | 心率快慢不同 |

对每一条无标签样本、每一种变换，**各以 50% 的概率决定"做还是不做"**。所以一条样本可能被做了 0 个、1 个……最多 6 个变换。

### 标签从哪来

不需要人标。做完变换后，**"这个变换有没有被施加"本身就是 0/1 标签**——施加了记 1，没施加记 0。一条样本得到 **6 个二值伪标签**。

### 网络怎么训

- **上游模型**：前面还是那 3 组"卷积 + 池化"（和下游一样），后面**分 6 个分支**，每个分支 2 层全连接，输出"这个变换有没有发生"。
- **损失**：6 个二分类交叉熵**直接相加**（作者认为 6 个任务同等重要）。

### 迁移什么

只把**第一层卷积**的权重搬到下游模型，并且**冻结**（不许再改）。其余层全部重新训练。

**为什么只迁第一层？** 第一层学到的是最通用的东西（局部波形、边缘），越往后的层越针对"这 6 个变换任务"本身，搬过去反而没用。

### 为什么这样能提升准确率

网络被迫学会分辨"噪声 / 音量 / 倒放 / 变速"这些干扰，等于**在正式学习五分类之前，先见过各种设备和录音条件**。所以：

- 主结果：98.65% → **99.435%**；
- 鲁棒性：信号起点随机化 + 加噪后，比不用 SSL 的模型高 **4–20%**；
- 作者还提到收敛更快。

### 一个类比

就像教人听乐器：先让他分辨"这段是不是被加速了、是不是倒放了、是不是有杂音"，再教他分辨"这是小提琴还是钢琴"。第一步不需要老师逐个标注曲目，只需要自动生成的"是/否"答案。

### 上游的"标签"是什么（2026-10-26 补充）

**不是疾病标签，也不是人标的。** 是程序自动生成的 **6 个 0/1**：

| 分支 | 标签含义 |
| --- | --- |
| 1 | 这条样本**有没有**加过噪声 |
| 2 | 有没有做过幅度缩放 |
| 3 | 有没有做幅值翻转 |
| 4 | 有没有做时间翻转 |
| 5 | 有没有做 10 段随机重排 |
| 6 | 有没有做 10 段拉伸/压缩 |

举例：一条无标签心音，程序抽签决定"加噪 + 时间翻转"两项施加，其余不做 →

```
样本 x'  ，标签 = [1, 0, 0, 1, 0, 0]
```

- **上游从来没见过 N / AS / MS / MR / MVP 这些类别**；CinC2016 原来的 normal/abnormal 标签被明确丢弃。
- 每条样本同时产生 **6 个二分类监督信号**，所以叫"多任务"。
- 标签是**程序算出来的**，不含人工判断，也不存在标注者间不一致。

**这也带来一个风险**：网络可能靠"捷径"过关——比如置换会留下段与段之间的**接缝**，网络只要学会找接缝就能答对，未必真的理解心音。原文没有针对这种捷径做分析。

### 上游怎么训、迁什么（再细一层）

**上游网络结构**

| 部分 | 内容 |
| --- | --- |
| 共享主干 | 和下游一样的 3 组"卷积(核 20，16/8/4 个滤波器) + 池化(4)" |
| 分支 | **6 个独立分支**，每个分支 **2 层全连接**（比下游的 1 层 FC 更深）|
| 每个分支输出 | **2 个值**（"该变换做了 / 没做"），softmax |
| 损失 | 6 个分支的二分类交叉熵**直接相加**（等权多任务）|
| 优化 | Adam |

**为什么分 6 个分支而不是一个 6 维输出**：共享主干学通用表示，每个任务一个"头"，避免 6 个任务在同一个输出层互相干扰。

**伪标签的生成**

- 对每条无标签样本、每种变换，**独立地以 50% 概率**决定做不做 → 期望每条样本被施加 **3 种**变换；
- 6 个 0/1 标签就是"这 6 种变换各自有没有发生"，**不需要任何人工标注**；
- 每个任务的类别比例大致 1:1（因为概率是 50%）。

**迁移的到底是什么**

- 只把**第一层卷积**的参数 $\theta_1$ 复制到下游，并**冻结**；
- 第一层是 1 通道输入 × **16 个滤波器** × **核长 20** + 16 个偏置 = **336 个参数**；
- 下游总参数 **20,193** → **迁移的只占 1.66%**，其余 98% 全部用 1,000 条有标签数据重训。

**为什么只迁一层？——作者给了实测理由**

原文（Discussion）：`transferring and freezing more than one convolutional layer of parameters to the downstream model leads to a performance decrement`。他们的解释是：小模型里冻结太多参数会**束缚下游**、把注意力从下游任务上拉走。

所以"只迁第一层"不是理论推导，是**试出来的**：迁多了反而掉点。

**效果**

- 准确率：98.65% → **99.435%**（CI 不重叠）；
- **收敛更快**：带 SSL 的模型训 **15 个 epoch** 就超过不带 SSL 训 **100 个 epoch** 的水平；
- 加噪越大，两者差距越大（Fig. 8a）。

**一个值得怀疑的点**：只迁 **336 个参数**就带来 0.8 个点的提升，幅度偏大。可能的解释是"冻结的第一层起到正则化/固定滤波器组的作用"，但作者**没有做"冻结 vs 微调"的对照**，所以无法区分是"学到了好特征"还是"冻结本身有益"。

### 代价与坑

- 需要**大量无标签数据**（它用了 CinC2016 的 4 个子库）和**额外一次上游训练**；
- 收益主要来自"鲁棒性"，**不保证换数据集也涨**（PASCAL 上只从 74.19% 到 79.78%）；
- "幅值翻转"这条在物理上有点可疑：心音的相位是有意义的，上下翻转不等于同一条信号，作者没解释为什么用它。

### 2026-10-26 你的复述

> 这个文章说的SSL就是让上游模型提前接触可能遇到的干扰，然后冻结第一层卷积层，再把上游模型被冻结的卷积层移动到下游的第一层吗

**逐字保留，未改写。** 大方向对，两处要改：

- **"提前接触干扰"只对了一半**。六种变换里，加噪、缩放、时间翻转、拉伸确实像现实干扰；但**置换（打乱 10 段顺序）和幅值翻转**是人为构造的"假任务"，现实中不会出现——它们的作用是**逼网络去理解时间结构**，不是模拟干扰。
- **顺序反了**。正确顺序是：
  1. 上游模型**正常训练**（6 个任务，全部参数可学，**没有冻结**）；
  2. 收敛后，**取出**第一层卷积的权重 θ1；
  3. **复制**到下游模型的第一层（两者形状相同：1 通道、16 滤波器、核长 20）；
  4. **在下游冻结**它，其余层用有标签数据重训。
  
  也就是"先训练 → 再取 → 再冻结"，不是"先冻结 → 再搬"。

- 还有一点：**上游模型本身训练完就被丢弃了**，只留第一层。说"移动"不算错，但更准确是"复制一层、其余扔掉"。

### 由上述矩阵计算（合计 1,000，各类 200）

| 条件 | accuracy | macro F1 | 逐类 F1（MR / MS / AS / MVP / N） |
| --- | --- | --- | --- |
| a) 无 SSL | 92.50% | **92.50%** | 0.9013 / 0.9126 / 0.9468 / 0.8967 / 0.9676 |
| b) 有 SSL | 96.10% | **96.09%** | 0.9320 / 0.9550 / 0.9698 / 0.9624 / 0.9852 |

**观察**
1. 两类条件都是**扰动数据**（随机起点 + 加噪），**不是 98.65% 的干净条件**；因此这两组 F1 **不能当复现门**。
2. SSL 在扰动数据上把 accuracy 从 92.50 提到 96.10（+3.60），macro F1 从 92.50 到 96.09（+3.59）——与原文“4–20% 提升”的表述方向一致（原文按不同噪声强度汇总）。
3. **最弱的两类是 MR（F1 0.932）与 MVP（0.962）**，混淆主要在 MR↔MVP、MS↔MVP——可作为误差分析切入点。
4. 干净条件（98.65%）原文**没有给混淆矩阵**，故 clean macro F1 **无文献锚点**，只能由本复现自报。
