## 数据

- 主数据集：**Yaseen 的 1,000 条**（5 类各 200），8 kHz
- **裁剪到 9,600 点**（8 kHz 下约 1.2 s），只要求"覆盖至少 1 个心动周期"
- 外部数据集：**PhysioNet/CinC2016**，3,240 条（**2,575 正常 / 665 异常**）
  - 原始 2 kHz、5–120 s；本文**重采样到 8 kHz**，并**只取前 1.2 s**
- 划分：**10 折交叉验证**（随机，无患者分组）
- 患者 ID：无

## 方法

- 预处理：**MODWT（最大重叠离散小波变换）平滑** + **z-score 归一化**
- 模型（3 层卷积 + BiLSTM）：
  - 输入 **[9600, 1]**
  - Conv1D：**核 64、16 个滤波器、步长 30**；后续卷积步长 2
  - 每层后接 **BN + ReLU**，前两个 ReLU 后加 **dropout 50%**
  - MaxPool：核 [2,1]、步长 [2,1]
  - **BiLSTM** → 全连接 → softmax 5 类
- 训练：**ADAM**，MATLAB R2020a；每折训练约 **30–45 s**
- 对比：CNN 单独、BiLSTM 单独、CNN-BiLSTM 三种

## 模型详解（2026-10-28）

### 结构（按原文）

```
输入 [9600, 1]（8 kHz × 1.2 s）
   │
Conv1D 核 64、16 滤波器、步长 30
   → BN → ReLU → dropout 50%
Conv1D 核 64、步长 2          ← 滤波器数原文未给
   → BN → ReLU → dropout 50%
Conv1D 核 64、步长 2          ← 滤波器数原文未给
   → BN → ReLU
MaxPool [2,1]，步长 [2,1]
   │
BiLSTM：每方向 100 单元 → 共 200
   │
全连接 → softmax(5)
```

- 三个卷积块结构相同（Conv1D + BN + ReLU），前两个后面加 **dropout 50%**；
- 第一层步长 **30** 是"粗下采样"（9,600 → 约 318 步），后面步长 2；
- BiLSTM 是**双向**：前向 100 + 反向 100，输出拼接。

### 尺寸推算（E4 估算，原文未给完整形状）

| 层 | 输出（估算）|

| 输入 | 9600 × 1 |

| Conv3（k64, s2）| 约 **33 × F3** |

### 消融：为什么"CNN + BiLSTM"而不是单独用

| 模型 | 平均 TP | AUC |
| --- | --- | --- |
| **CNN-BiLSTM** | **98.30%** | **0.998** |
| 仅 CNN | 95.80% | 0.994 |
| 仅 BiLSTM | 92.64% | 0.966 |
| CNN-LSTM（同样 100 单元）| 96.30% | 0.997 |
| CNN-GRU（同样 100 单元）| 95.7% | 0.996 |

→ **CNN 负责局部形态，BiLSTM 负责时序；两者组合确实比单独用好**，而且 BiLSTM 优于同规模的 LSTM/GRU。

### 三处需要打问号

1. **hold-out（70/30）上准确率 100%** —— 这种数字通常意味着划分或样本量有问题，不能当真。
2. **仅 BiLSTM 的 92.64%** 说明序列模型单独用不行——它没有卷积的局部特征提取能力。
3. **输入只取前 1.2 s**，而 Yaseen 录音约 3 s——**丢掉一半以上信号**，99.32% 是"截断后"的成绩。

## 读完带走什么（2026-10-28 收尾）

### 五条可用的

| # | 结论 | 怎么用 |
| --- | --- | --- |
| 1 | **外部验证掉点 = 99.32% → 87.31%**，但外部是**二分类**、异常 TP 只有 **66.17%** | 引用时必须写清任务变了；这比"掉了 12 个点"更准确 |
| 2 | **掉点的三个可控因素**：任务定义（五类→二类）、**只取 1.2 s**、域差（8 kHz CD vs 2 kHz 临床）| 我们做外部验证时，先固定"任务、时长、采样率"，否则分不清是模型问题还是设置问题 |
| 3 | **MODWT 平滑 + z-score** 可以替代"带通 + z-score" | 当 A1 的前端对照；但 21 没做消融，**不能声称更好**（见 ADR-025）|
| 4 | **粗下采样卷积 + BiLSTM** 的组合有效（CNN 95.80 / BiLSTM 92.64 / 组合 98.30）| 若 A3 的纯 CNN 不够，可加一层双向 LSTM 作对照 |
| 5 | **dropout 只加在前两个卷积块**、首层步长 30 | 小模型里"先粗降采样再交给序列层"是省算力的常用手法 |

### 三条不能照搬的

1. **参数量不可复现**：第二、三层滤波器数只在图里，正文没写；
2. **hold-out 100%**：不可信，不能当参照；
3. **1.2 s 输入**：对 Yaseen（约 3 s）是信息损失，不能直接说"我们用 2 s 更好/更差"。

### 对我们的具体动作

- **ADR-025** 已经有 MODWT vs DWT 的讨论；这篇是"MODWT 用于平滑波形"的实例，支持"任务决定表示"这个判断；
- 若做 **A3 的序列化变体**：可按"首层大步长 + 3 个卷积块 + BiLSTM(≤64)"设计，并**先算参数量**——按 100 单元粗估，仅 BiLSTM 就可能 >130k 参数（E4 估算），大概率超预算，需缩到 32/64 单元；
- **外部验证设计**：照它的教训，先统一采样率与时长，再报"二分类"与"五分类"两套结果，别混着说。

## 与我的 FYP 的关系

- **它确实证明了"换数据集就掉"**：99.32% → 87.31%。但必须说清：**外部是二分类**（正常 vs 任何异常），不是五分类外部验证。04 只写了两个百分数，容易让人误以为同一任务。
- 掉点原因至少三个，而且**都不是"模型不行"**：
  1. **任务变了**：Yaseen 五分类 → CinC2016 二分类，而"异常"里还包含 CAD、主动脉手术等**非瓣膜病**；
  2. **只取前 1.2 s**：CinC 录音 5–120 s，砍到 1.2 s 丢掉绝大部分信息；
  3. **域差**：8 kHz 教学 CD vs 2 kHz 多来源临床录音。
- 可借鉴：
  - **MODWT 平滑 + z-score** 比"带通 + z-score"更轻，可当 A1 的对照；
  - 结构很浅（3 层卷积 + BiLSTM），复杂度确实低，但**没报参数量**。
- 不能用的：
  - **不能把 87.31% 当"五分类外部性能"**；
  - 不能直接说"BiLSTM 必要"——要看它 Table 2–3 里 CNN 单独与 CNN-BiLSTM 的差；
  - 1.2 s 截断本身对 Yaseen（约 3 s）就是信息损失，99.32% 是在**截断后**的数据上得到的。
