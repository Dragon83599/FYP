## 数据

- 训练：Eko CORE / DUO 云库里 **5,878 条录音、>34 小时、来自 5,318 名患者**（从 40 万条中抽）
  - 标注：**1 名医生**分三类（有杂音 / 无杂音 / 信号不合格）
- 验证：**入组 962 人，954 人可分析**；四个听诊位
- 金标准：**超声报告**（none/mild/moderate/severe/critical）+ **3 名专家心内科医生**听诊标注（多数票；信号质量/杂音等级取中位数）
- 专家一致性：**κ = 0.478**（中等）
- 划分：训练/内部测试/验证**完全分开**，验证集是为本研究专门采集的
- 患者 ID：有

## 方法

- 预处理：**8 阶 Butterworth 高通 30 Hz** → **降采到 2,000 Hz**
- 模型：**1D ResNet，34 层**（每层 = 1D 卷积 + ReLU + BN + dropout + maxpool，残差连接）
- 输出：**3 类**（杂音 / 无杂音 / 信号不合格），softmax
- 训练：随机初始化，**ADAM**
- 推理链条：先判"信号是否合格"（不合格直接输出），合格再判有无杂音；**阈值在训练时固定**

**逐字保留，未改写。** 同意"不必精读"——预处理（30 Hz 高通 + 2 kHz）和 34 层 ResNet 都不是我们能用的。但**有 5 个点值得拿走**，都不在预处理和模型上。

**先补一句 ResNet**：残差网络的核心是**跳连**（$y=F(x)+x$），让梯度能绕过若干层直接回传，因此能堆很深而不退化。34 层 1D ResNet 的参数量原文没给；按常见 1D 配置（通道 64→128→256→512）**粗估在 50 万–200 万量级**（E4 估算，未核实），仍远超我们 15 万的预算。

#### 值得拿走的 5 点

| # | 原文做法 | 为什么有用 | 我们怎么用 |
| --- | --- | --- | --- |
| 1 | **输出 3 类：杂音 / 无杂音 / 信号不合格** | 设备端最常见的失败不是"判错病"，而是"录得太差" | 我们的设备可以加一个**质量门**：不合格直接提示重录，而不是硬给五类 |
| 2 | **两级阈值**：先判质量，再判杂音；阈值在训练时固定 | 推理链简单、可解释、易部署 | 对应我们 plan 里"信号不合格"的处理（现在只有端点检测，没有质量分类）|
| 3 | **报似然比（LR+ / LR−）**：杂音 8.89 / 0.259；AS 6.68 / 0.08；MR 12.3 / 0.357 | LR **不随患病率变化**，比 PPV 更稳；临床上也更好解释 | 我们报 macro F1 之外，可以加 LR+ / LR− |
| 4 | **样本量按"目标 LR ≥ 5、95% 置信"反推**：每组 110 例 | 简单、可写进方法章 | 我们若做外部验证或用 holdout，可以照这个思路估样本量 |
| 5 | **人和算法对比要同操作点**：专家 A 的 AS 敏感度 97.5%、特异度只有 45.1% | 不同阈值下比"谁更强"没有意义 | 我们若引用"模型超过医生"，必须先说明阈值/操作点 |

#### 两条偏"讨论"的素材

- **AS 与 MR 的难度不对称有临床解释**：AS 是固定位置的收缩期喷射性杂音；MR 是**负荷依赖、方向性强**的杂音，不一定在预设听诊点出现。这能解释为什么我们五分类里 MR/MVP 容易混。
- **训练标签与验证标签质量不同**：训练用 1 名医生，验证用 3 名专家多数票（κ=0.478）。这提示"训练标签噪声"是常态，写 limitation 时可以引。

#### 不建议学的

- 34 层 ResNet（超预算）；
- 30 Hz 高通 + 2 kHz（我们 ADR-002 是 20–1000 Hz、4 kHz）；
- 病例-对照富集的验证设计（不能外推到筛查人群）。

## 与我的 FYP 的关系

- 可借鉴：
  1. **34 层 1D ResNet、2 kHz、30 Hz 高通**——和我们 A3（1D CNN、4 kHz）同族，但它证明了"低采样率 + 纯 1D 卷积"在真实临床数据上可行；
  2. **三分类里带"信号不合格"类**——这是很实用的设计：先拒识，再分类；
  3. **训练用 1 名医生标、验证用 3 名专家多数票**——成本可控又不失严谨。
- 可改进 / 注意：
  - **验证集是"病例-对照"式富集**（73 AS / 172 对照等），不是连续筛查人群，所以敏感度/特异度**不能直接外推到普通人群**；
  - 训练标签只来自**一名医生**，验证标签才用三人多数票——两套标准不一致；
  - 设备是单一厂商（Eko），换设备的表现未知；
  - 作者自己承认：**算法和专家在 AS 上都比 MR 强得多**。
- **对 04 的核对**：04 写 "5,318 名患者训练 CNN … 敏感度 76.3% / 特异度 91.4%"。**两个数字都对**，但注意 **5,318 是训练集人数**，验证是 962 人——04 把两个数放在一句话里，容易让人误以为 "5,318 人验证得到 76.3%"。
- 不能用的部分：
  - 不能把 93.2% 当"AS 筛查敏感度"通用值——这是**富集队列**上的结果；
  - 不能引它做五分类——它只做"有无杂音 + AS/MR 两个二分类"。
