## 方法

三阶段级联：

1. **时频表示 + 带通**：先算 STFT，再选对异常最相关的频带；
2. **ONMF（正交非负矩阵分解）**：把时频矩阵分解为
   - **W：谱模式（basis）**
   - **H：时间激活（activation）**
3. **CNN 分类**：把 W 或 H 当输入，比较六种结构——**UjaNet、LeNet5、AlexNet、ResNet50、VGG16、GoogLeNet**

## 结果（原文数字）

| 对比 | 提升 |
| --- | --- |
| **ONMF 时间特征（H）vs 谱特征（W）** | **约 45%** |
| ONMF 激活矩阵 vs STFT 谱图（UjaNet）| 35% |
| 同上（LeNet5 / AlexNet / ResNet50 / VGG16 / GoogLeNet）| 30% / 23% / 10% / 8% / 6% |
| 用 ONMF 时的准确率范围 | **93%（AlexNet）～ 98%（GoogLeNet）** |

**关键结论**：**低复杂度 CNN（UjaNet、LeNet5）配 ONMF 时间特征，能达到与大模型（VGG16/GoogLeNet）相当的水平**——说明"输入表示"比"模型深度"更重要。

### 第 3 站：ONMF 在做什么（用一个式子说清）

把一段心音的时频矩阵 **X** 分解成两个非负矩阵：

```
X (频率 × 时间) ≈ W (频率 × K) · H (K × 时间)
```

- **W 的每一列 = 一个"谱模式"**（像一种声音的频谱指纹）；
- **H 的每一行 = 该模式随时间的激活强度**；
- **K = 秩**，即"用几种基本声音来解释这段心音"。

**作者的核心发现**：把 **H（时间激活）** 当 CNN 输入，比把 **W（谱模式）** 或原始 STFT 喂进去都更好。

**为什么？** 正常心音的节律是**周期性的**；瓣膜病会**打断这种周期**。H 恰好编码了"什么时候有哪种声音"，所以最能反映"节律是否被破坏"。

### 第 5 站：结果的正确读法

| 对比 | 提升幅度 |
| --- | --- |
| H vs **W** | **约 45%** |
| H vs **STFT**（UjaNet）| 35% |
| H vs STFT（LeNet5 / AlexNet / ResNet50 / VGG16 / GoogLeNet）| 30 / 23 / 10 / 8 / 6% |
| 用 H 时的绝对准确率 | **93%（AlexNet）～98%（GoogLeNet）** |

**关键洞察**：模型越简单，收益越大（UjaNet +35%，GoogLeNet 只有 +6%）——说明**表示好，可以替代模型深度**。

### 三处要留意

1. **二分类**：不能与五分类的 99% 横比；
2. **200 vs 800 不平衡**：原文没看到重采样/加权处理（待查证）；
3. **K（秩）是搜出来的**：在完整数据上搜超参，存在"在同一评估集上选模型"的偏倚（与 26 的 17×13 同类问题）。

## 我认为重要的点（原话/你的理解）

- **2026-10-28，自测题回答（原话）**：> 因为心音的时间特征比频率特征明显吧
  - 方向对，但更准确的说法是：**"节律是否被破坏"是二分类里最稳定的判别线索，而谱模式在正常/异常之间大量共享**。
  - 具体机制：**W（谱模式）里既有 S1/S2 的模式，也有杂音的模式**，正常与异常都会用到其中一部分 → W 本身区分度低；**H（时间激活）编码的是"哪种声音在什么时候出现"**，正常心音呈**周期性重复**，瓣膜病**打断这种重复** → H 的判别力强。
  - **一个重要的边界**：这个结论是在**二分类**（正常 vs 任何异常）下得到的。若任务是**五分类**（区分 AS/MR/MS/MVP），**频率信息就变得关键**（不同病变的杂音频谱形状不同），"H 优于 W"未必成立。**不能直接搬到我们的五分类任务上。**
