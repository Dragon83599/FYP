# FYP 范围与"足够"的判定（2026-10-18）

> 用途：给毕设设一把尺子，避免"要不要再做点别的"反复消耗时间。本文定义
> **必须 / 应该 / 不做**，并为每项给出证据出处。评审问到时，按第 4 节查表。
>
> 状态：范围契约，随证据更新；不是冻结文档。

## 1. 先说清楚"够"是什么意思

本科毕设的交付物不是"临床可用的 AI"，而是**一个可辩护的工程系统**：

1. 问题定义清楚，且有临床理由；
2. 系统边界与接口冻结；
3. 数据来源、许可、患者级划分可核查；
4. 模型有多组对照，不是"训练了一个网络"；
5. 指标是患者级、带区间、有工作点，不是单个准确率；
6. 部署有实测资源数据（或明确标注"未上板"）；
7. 失败被记录、被解释，而不是被藏起来；
8. 任何人能按文档复现上述数字。

**本仓库已经满足 1–5、7、8，第 6 项除上板外全部完成。**

### 2.3 不做（并写明理由，避免被反复提起）

| 项 | 理由 |
| --- | --- |
| 疾病诊断（VSD/ASD/PFO 等） | CirCor 无病理标签；ZCHSound 许可未确认；超出 MVP |
| 杂音分级 / 位置 / 放射方向 | 数据集没有这些标注 |
| 多位置融合 | 需要多位置同步采集协议 |
| 换树莓派 | 精度理由已消失：TCN 能在 S3 上跑（324 KiB flash 权重、31 KiB 激活） |
| 手机 / 服务器推理 | ADR-007 修订明确禁止外移推理 |
| 临床有效性结论 | 单数据集、回顾性、无外部队列 |

## 3. "完成"的判定条件

全部勾选才算完成：

- [ ] INT8 掉点已测且 ≤0.03（或已记录超限与原因）
- [ ] TCN 或小 CNN 的端侧部署路径已确定（ESP-DL / TFLite Micro 转换成功）
- [ ] 首次上板：MTU/PHY/CCCD 顺序、5 分钟丢帧、P95 推理时延、峰值堆、电流
- [ ] 外部或域偏移验证至少一组完成
- [ ] 答辩材料包含每项决策的候选对比与失败判据

## 5. 诚实清单：目前仍然没有的东西

1. **没有任何上板数据**（时延、电流、堆余量、屏幕）；
2. **INT8 精度未测**（所有已发布数字都是 FP32）；
3. **没有外部队列**（只有 CirCor，儿科/青年，单一采集协议）；
4. **S1/S2 未达标**（嵌套 0.7975 < 0.80，高心率互换 0.27）；
5. **心率有 13.5% 粗错**；
6. **TCN 增益可能是录音级捷径**（交叉验证进行中）。

这些不是"待补的漏洞"，而是**已知边界**。答辩时主动说出来，比被问出来强。
