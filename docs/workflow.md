# 五分类 VHD 端侧筛查：执行手册（2026-10-29 定稿）

> 这是**执行版**：所有参数已定，可直接照做。
> 依据与推导见：`plan-5class-vhd.md`（设计）、`engineering-decision-register.md`（ADR-020～033）、
> `parameter-ledger.md`（出处）、`parameter-rationale.md`（理由卡）、`workflow-evidence.md`（逐条证据）。
> **没有文献依据的参数，一律标 E4；论文里不得写成"文献表明"。**

## 0. 一句话

在 **Yaseen 1,000 条（5×200）** 上做**单标签五分类**；用 **8 个臂**回答"表示与模型各贡献多少"；按**录音分组嵌套 CV + holdout** 评估；最终**双轨部署**（树莓派 4B 参考 / ESP32-S3 int8），并报告**部署代价**。

## 1. 数据

| 用途 | 数据 | 规模 | 备注 |
| --- | --- | --- | --- |
| **主实验** | Yaseen | 1,000 条（5×200），8 kHz | 无患者 ID → 只能按**录音**分组 |
| **A6 无标签预训练** | CirCor（ODC-By 许可）| 本地 3,163 条 / 942 人 | 只丢标签使用；**不做外部验证** |
| 不使用 | CinC2016、HSS、PASCAL | — | 任务不匹配 |

**边界**：音频不随论文发布；单标签 → 不声称能识别合并病变。

## 2. 预处理（全部参数）

```
解包 → 端点检测 → 重采样 2 kHz → 带通 20–1000 Hz → z-score → 切窗
```

| 步 | 参数 | 出处 |
| --- | --- | --- |
| 解包 | libarchive 读 `.rar` | 工程 |
| 端点检测 | 25 ms 帧 / 10 ms 移；阈值 = 噪声底 × 3 | **E4** |
| **重采样** | **2 kHz**（A3-repro 用 1 kHz）| 20、15【文献】 |
| 带通 | 4 阶 Butterworth **20–1000 Hz**，**零相位 `sosfiltfilt`** | 22、27、15【文献】+ E4（实现选择）|
| 归一化 | 每窗 z-score | 21【文献】 |
| 切窗 | **2 s / 1 s**；短窗两端补零；A3-1.5s 用 1.5 s | 17【文献】+ E4 |
| **质量门** | BER（目标带 ÷ 噪声带）；**窗级**判拒；阈值在训练折内按分位数取（默认拒 10%）| 26【文献】+ E4 |

## 3. 实验主线（2026-10-31 变更，ADR-041 候选）

**主线改为"文献锚定 + 单点改进"**：先复现三篇已端侧部署的文献，再逐轴改进。

| 角色 | 臂 | 配置 | 原文结果 |
| --- | --- | --- | --- |
| 手机复现 | **L17** | 1 kHz / 2 s / 2,000 点 / 16-8-4 / FC128 | 20,193 参数，98.65% |
| SBC 复现 | **L26** | 32 mel / 0.2 s 帧 / 17×13 / WCNN | 312,357 参数，99.6% |
| MCU 复现 | **L27** | 1 kHz / 1.5 s HSMM / 分组卷积 | 52,670 参数，PC 99.4% |
| 桥接（保留）| A1、A2s | MFCC / log-mel + 浅层 | 分钟级 |

**单轴改进**（每条一个臂，配对 bootstrap，≥0.5 点且 CI 不含 0 才纳入）：
I1 窗长 1.5s→2s；I2 采样率 1→2 kHz；I3 表示（波形/MFCC/log-mel）；I4 结构（FC/分组卷积）；I5 训练（增强/SSL/3 种子）；I6 聚合（录音级）。

## 3.1 原 8 臂（保留为备选方案）

## 3. 实验臂（8 个）

| 臂 | 表示 | 模型 | 参数（E4）| 作用 |
| --- | --- | --- | --- | --- |
| **A1** | MFCC+Δ+ΔΔ（池化 78 维）| LR / RBF-SVM | <2k | 手写特征基线 |
| **A2s** | log-mel（池化 128 维）| LR / SVM（同 A1）| <2k | **桥接：表示效应** |
| **A1c** | MFCC 39×200 | 2D CNN（8/16/32）| 约 6.1k | **补全 2×2** |
| **A2** | log-mel 64×200 | 同 A1c 模板 | 约 6.0k | 图像式表示 |
| **A3-repro** | 1D 波形 1 kHz / 2,000 点 | **17 原结构**（16/8/4、核 20、池化 4、tanh、FC 128）| **20,193** | 复现锚点 |
| **A3** | 1D 波形 2 kHz / 4,000 点 | 16/8/4、**核 40（=20 ms）**、池化 4、tanh、FC 128 | 约 39.6k | **端侧主线** |
| **A3-1.5s** | 1D 波形 3,000 点 | 同 A3 | 约 31k | 窗长对照 |
| **A6** | 同 A3 | 预训练四组 | 约 39.6k | SSL（Ma 式 vs Soni 式）|

### 3.1 2×2 归因（严格控变量）

```
              浅层(LR/SVM)        CNN
MFCC      A1  ────────────  A1c
          │ 表示效应↑        │ 表示效应↑
log-mel   A2s ────────────  A2
             模型效应→          模型效应→
```

- 控制项：**同一组 64 mel / 900 Hz**、**25 ms / 10 ms**、**均值+标准差池化**、**同一分类器与网格**、**同一 CNN 模板与训练超参**、**同一划分索引与种子**；
- **A3 不参与归因**（原始波形 + 浅层分类器无可行实现），只作系统级对比。

### 3.2 训练（ADR-030）

| 项 | 值 |
| --- | --- |
| 优化器 / lr | Adam / **1e-3**（26 的文献值）|
| batch / epochs | **32** / 最多 **100**（早停 patience 10，看验证 macro F1）|
| dropout | 0.3 |
| 种子 | 主臂 **3 个**（42/123/2024）；A3-repro / A3-1.5s / A6 各 1 个 |

## 4. 评估（ADR-031）

| 项 | 做法 |
| --- | --- |
| 外层 | **5 折**，按类别分层，**同一录音不跨折** |
| 内层 | 仅浅层臂做网格；CNN 臂超参固定 |
| holdout | **15%**，全部臂跑完后**只测一次** |
| **单位** | **窗级（主）+ 录音级（辅）**；录音级用 **soft voting**（概率平均）|
| 指标 | **macro F1**（主）+ 逐类 F1 + 混淆矩阵 + kappa + accuracy |
| CI | 按**录音** cluster bootstrap **1,000 次** |
| 显著性 | **配对 bootstrap** 的差值 CI，**不跨 0** 才算显著 |
| 种子 | 3 个种子的**概率平均**为主结果；另报**指标级 std** |
| 质量门 | 报**窗覆盖率 + 录音覆盖率 + 接受子集 F1 + 完整曲线** |
| 禁止 | 测试折/holdout 选型；只报窗级；只报单种子；静默丢低质量；用 CI 重叠当唯一判据 |

## 5. 部署（ADR-032）

| 项 | 做法 |
| --- | --- |
| **板端测试集** | **holdout 15%**（用 85% 训练的单一模型），只测一次 |
| **三轨** | ① **手机 PWA**（TensorFlow.js，第一优先）② **树莓派 4B** 浮点（参考轨）③ **ESP32-S3** int8（部署轨/卖点）|
| **时延** | **纯推理 + 端到端**（含重采样/带通/z-score/特征）都报；**RTF 用端到端** |
| 门槛 | RTF ≤1.2（失败 >1.5）；端到端 ≤5 s（失败 >10 s）|
| **掉点** | 上板 vs 浮点 **≤2 点**；超过按三级回退 |
| 三级回退 | ① PTQ→QAT ② 缩输入 1.5 s / 换 ESP32-P4 ③ **放弃 S3，保留 PWA + 树莓派两轨**并如实记录 |
| 报告 | 精度（窗/录音）、两种时延、**峰值 RAM**、**Flash**、**体积 KB**；**不报功耗**（无功率计）|
| 测量 | 预热 10 次丢弃；**100 次**；报**中位 + P95**；关闭串口打印 |

## 6. 四周计划（ADR-033）

| 周 | 任务 | 验收门 |
| --- | --- | --- |
| **W1** | 预处理 + 划分索引 + 评估框架 + A1/A2s | 全 1,000 条产出一致窗；划分可复现；A1 出首版 F1 |
| **W2** | **A3** + A3-repro + A1c + A2 | **A3-repro 落在 98.65% ±1.5 点**；2×2 齐全 |
| **W3** | **A6** + 质量门 + PTQ | A6 有 CI；覆盖率曲线；PTQ 掉点 <2 点 |
| **W4** | 双轨部署 + 实测 + 写作 | 上板精度、端到端时延、RAM 齐全 |

**落后时降级顺序**：A3-1.5s → A1c/A2s 改 1 种子 → A2 改 1 种子 → 质量门降为分析 → 部署单轨。
**必保**：A3、A6、双轨的上板三项数。
