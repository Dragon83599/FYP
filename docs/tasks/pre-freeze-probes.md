# 方法定型前的廉价预检（2026-10-30 制定）

> 背景：W1 已执行，但**实验方法尚未定型**（例如 27 用 HSMM 分割，可能比我们的固定窗更好）。
> 原则：**先用最小成本回答"要不要改方法"，再决定是否投入全量训练。**
> 不做的事：暂不跑 8 个臂的完整结果（避免方法一改全部白跑）。

## 为什么可以先做预检：成本对比

| 动作 | 成本 | 说明 |
| --- | --- | --- |
| 重跑预处理（改切窗/滤波/采样率）| **约 6 秒** | ADR-037 记录：全流程 6 s |
| 跑一个 **A1**（1 种子 × 5 折）| **分钟级** | 浅层模型，特征已缓存 |
| 跑 8 个臂（3 种子）| **数小时** | 105 次训练 —— 这才是"白跑"的代价 |

→ **所以：预检可以做，全量先等。**

## 三个预检（全部只用 A1，1 种子）

| # | 预检 | 变体 | 成本 | 决定什么 |
| --- | --- | --- | --- | --- |
| **P1** | **对齐 vs 固定窗** | 固定窗（现状）vs S1 对齐（平移不重切）| 半天 | ADR-039：要不要引入对齐 |
| **P2** | **2 kHz vs 4 kHz** | 同 A1 特征，两种采样率 | 半天 | ADR-029：2 kHz 是否够 |
| **P3** | **20–1000 vs 20–400 Hz** | 同 A1 特征，两种带通 | 半天 | ADR-029 子决策 2：高频有没有用 |

**统一口径**：同一 `splits.json`、A1 同超参、报**窗级 macro F1 + 配对 bootstrap 差值 CI**。

## 判据（提前写死，避免"看完数字再找理由"）

| 预检 | 结论 A（改方法）| 结论 B（不改）|
| --- | --- | --- |
| P1 对齐 | 提升 **>1.5 点** → 纳入主线 | **<0.5 点** → 保持固定窗 |
| P2 采样率 | 2 kHz 低 **>1.5 点** → 回退 4 kHz | 差 **<1 点** → 保持 2 kHz |
| P3 带通 | 20–400 高 **>1 点** → 说明高频无用，改频段 | 20–1000 不差 → 保持现状 |

**中间地带（0.5–1.5 点）**：不自动改，交由组会/老师判断，并在论文写成"差异不显著"。

## 预检后的"定型点"

三个预检都有结论后，才进入 **W2 全量**，并把结论写进：

1. `ADR-029`（采样率/带通）或 `ADR-039`（对齐）的状态：**候选 → 已定**；
2. `parameter-ledger.md`：更新对应参数；
3. 重新生成 `splits.json` 与 `windows.csv`（若要改切窗），**旧档保留**在 `data/processed/archive/`。

## 预检期间允许做的

- 读文献补证据（如 HSMM 分割的实现难度、S1/S2 检测的现成算法）
- 写代码框架（数据加载、训练循环、评估函数），**但不跑全量**
- 准备 PPT / 组会材料

## 预检期间不允许做的

- 用 holdout 做任何选择
- 把预检结果当"最终结果"写进论文
- 在预检未完成时改多个变量（一次只改一个）
