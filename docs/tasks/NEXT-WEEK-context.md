## 3. W2 的两件事

### 3.1 PWA 数据通路（半天）
- 目标形态：`tf.loadLayersModel()` 加载 `model.json` + 权重；输入 → 预处理 → `predict()` → 五类概率。
- 一致性判据：**同一 wav 在 Python 与浏览器各跑一遍，概率最大绝对差 <1e-3**。
- 托管/局域网细节见 `docs/tasks/pwa-demo-hosting-options.md`（Service Worker 需 HTTPS；`ws://` 与 HTTPS 页面混合内容会被拦）。

### 3.2 复现 Ma 等（1–2 天）

**论文明确给出的（照抄）**

| 项 | 值 |
| --- | --- |
| 输入 | **2,000 点**（1 kHz × 2 s），非重叠切窗 |
| 结构 | 3 × (Conv1D 核 20 + maxpool 4)，滤波 16/8/4；FC 128；tanh；softmax 5 |
| **参数量（自检）** | **必须等于 20,193** |
| 损失/优化 | categorical cross-entropy + **Adam** |
| 预处理 | 降采 1 kHz → 切窗 → **min-max 缩放**；**不做带通** |
| 划分 | 10 折（原文随机折，无录音分组）；报告 98.65%（CI 98.555–98.745）|

**论文没给的（需自己定，且必须记录）**
- 学习率、训练轮数、训练 batch size、每条录音切出多少窗、SSL 上游（epochs/LR/无标签语料规模）。
- **无代码公开**（无 code availability；补充材料只有架构图与能耗表）。

**关键口径提醒**：**复现必须用论文的预处理（1 kHz + min-max，无带通）**，不能用本项目 2 kHz 流程；否则不是复现，数字不可比。改进阶段再切回本项目流程。

**建议起步超参（E4，需在 dev 集上调）**：Adam，LR 1e-3，50–100 epoch + 按验证损失早停，batch 32；只有当结果偏离 ±3 点时才在训练折上做小范围搜索，**不得触碰 holdout**。

## 4. 验收与失败判据

| 项 | 值 |
| --- | --- |
| 复现验收（accuracy，仅对文）| **98.65% ±1.5 点** |
| **模型质量主指标** | **macro F1（+ 95% CI + 逐类 F1 + 混淆矩阵）**；accuracy 不用于判断好坏（ADR-053）|
| **F1 锚点** | 原文无 F1，但 Fig. 7 混淆矩阵可算：**扰动条件下 macro F1 = 92.50%（无 SSL）/ 96.09%（有 SSL）**——**只能对扰动协议，不能当复现门**；干净条件 F1 无锚点 |
| 允许偏差 | 随机折 → 录音分组折，预期掉 1–3 点，**掉了要能解释** |
| 失败判据 | 掉出 **±3 点**且无法解释 → **停止改进**，回查预处理与划分 |
| 端上验收 | 中位 **≤1 s**、P95 **≤2 s**、一致性 **<1e-3** |
