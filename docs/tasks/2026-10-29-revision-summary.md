# 修订摘要：改了什么 / 为什么 / 依据哪篇（2026-10-29）

## 一句话

**流水线五步里，只动采样率（4 → 2 kHz）与窗长（A3 增设 1.5 s）；带通与端点检测保持不变。** 评估协议补了 holdout、资源报告与质量门覆盖率。

## 一、改了什么

| # | 位置 | 改动 | 类型 |
| --- | --- | --- | --- |
| 1 | plan §2 表格 | 修复被 ADR-028 提示打断的表格 | 修复 |
| 2 | plan §2.1（新增）| 五步的"现状 / 依据 / 反例 / 候选 / 建议"对照表 | 新增 |
| 3 | plan §2 下采样注 | 采样率建议改 **2 kHz**（ADR-029）| 建议 |
| 4 | plan §4.1（新增）| holdout、录音分组、资源报告、上板精度、质量门覆盖率 | 新增 |
| 5 | ADR-029（新增）| 采样率 / 带通 / 窗长三个子决策（候选）| 新决策 |

## 二、为什么

| 改动 | 理由 | 依据 |
| --- | --- | --- |
| **4 kHz → 2 kHz** | 算力 ∝ 输入长度；20 在 2 kHz 上做到 99.6% | 20、27、T3b |
| **A3 增设 1.5 s** | 与 27 一致，输入长度 ×0.75，更接近 RTF 目标 | 27、ADR-027 |
| **带通不动** | 22 指出异常成分到 500–600 Hz；23 的 20–150 Hz 不可外推 | 22、23 |
| **端点检测不动** | 27 的 Springer 分割收益未在我们数据上验证，先做对照再换 | 27 |
| **holdout 只测一次** | 12、16 都在测试集上调参 | T4 |
| **资源必须全报** | 22 篇里只有 4 篇报全 | T3 |
| **质量门要报覆盖率** | 静默丢弃会虚高指标 | 25、ADR-028 |

## 三、没改什么（也很重要）

| 项 | 为什么不动 |
| --- | --- |
| 20–1000 Hz 带通 | 证据不足；砍到 400 Hz 有削掉 AS/MR 的风险 |
| 能量端点检测 | Springer 分割需要额外训练数据与代码，收益未验证 |
| z-score | 01、21 都用；20 未提归一化（待查证），但去掉没有收益证据 |
| A1–A6 的臂结构 | 与 ADR-020/022–028 一致，无需改 |

## 四、下一步（要实验才能定的）

1. **2 kHz vs 4 kHz**：同一 A1 特征、同一录音分组 5 折，比 macro F1 + CI（失败判据：低 >1.5 点 → 回退）；
2. **20–400 Hz vs 20–1000 Hz**：同法（失败判据：低 >1 点 → 保留现状）；
3. **1.5 s vs 2 s（A3）**：同法（失败判据：低 >1 点 → 保留 2 s）；
4. 若三项都不显著，**全部回退到现行参数**，文献只作讨论。

## 五、引用注意

- 20 的 99.6%、27 的 99.4% 都是**Yaseen 随机划分**结果，**不能当我们的预期**；
- 23 的 98.60% 来自**干净 CD + 20–150 Hz**，只能作为"带通可以很窄"的旁证，不能作为默认；
- 24/29 的 44.1 kHz 是**反例**，不要照搬。
