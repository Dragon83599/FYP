# W3 计划（唯一任务队列）

> **这份文件是 W3 阶段的唯一计划来源。**
> 计划只能通过修改本文件变更，不能通过对话变更。
> 每轮开始：先读本文件，声明"我在做第 X 项"；每轮结束：更新状态。
>
> 建立时间：2026-11-09。最后更新：2026-11-09。

## 0. 变更规则

| 规则 | 内容 |
| --- | --- |
| R1 | 对话中出现的新想法**默认进入"候选池"**，不进入队列，除非用户明确说"先做这个"。 |
| R2 | 只有**新证据**（实验推翻某个假设、论文更正、用户纠正方法错误）可以改变队列顺序。改的时候要在 §5 记一行。 |
| R3 | 队列长度上限 **4 项**。超过 4 项时，新任务只能进候选池。 |
| R4 | 每项必须有**验收标准**，没有验收标准的不进队列。 |
| R5 | 同一时间只做一项；一项未完成不开下一项（并行训练可以，但推理/写文档不并行）。 |
