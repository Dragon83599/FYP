## 2. 端点检测（1 小时）

- [ ] 帧长 **25 ms**、帧移 **10 ms**，短时能量
- [ ] 噪声底估计：取能量序列的 **10 分位**；阈值 = 噪声底 × **3**
- [ ] 剪掉首尾低于阈值的帧；保留中间（不处理内部静音）
- [ ] 若剪后长度 <0.5 s → 标记为**异常**，列入清单人工检查

**验收**：抽 30 条，比较自动端点与人工标注的起止，**中位差 <100 ms**。

## 3+4. 带通与重采样：**顺序已由 ADR-036 改为"先 8 kHz 带通，再 1/4 抽取"**

> 原清单是"先 2 kHz 再带通"，但 **2 kHz 的 Nyquist 正好 1,000 Hz**，数字滤波器上边沿不能等于 Nyquist
> （`butter` 会直接报错）。ADR-036 实测后改为：**在 8 kHz 上做 20–1000 Hz 零相位带通 → `resample_poly` 1/4 抽取**。
> 频段与阶数一字未改。

- [x] 8 kHz 上零相位带通 20–1000 Hz（4 阶，SOS，`sosfiltfilt`）→ 见 ADR-034/036
- [x] 再 `resample_poly(up=1, down=4)` 抽取到 2 kHz
- [x] 抗混叠实测：2.6 kHz 单音残余 **−69.1 dB**（简单抽取为 −0.0 dB）

**验收（已过）**：−3 dB 点 **20.02 / 999.45 Hz**；2.6 kHz 残余 < −40 dB（实测 −69.1 dB）。

## 4. （原）带通 20–1000 Hz

- [ ] 4 阶 Butterworth，`sos` 形式（数值更稳）
- [x] **已定（2026-10-29）：用 `sosfiltfilt`（零相位）**
  - **建议 `sosfiltfilt`**：避免相位偏移（心音 S1/S2 的相对时序有意义）；
  - **前提**：部署端也要用同样的零相位实现（2 s 窗可整段缓冲，可行）；
  - **代价**：计算量约 2 倍，且需要整段数据（不能流式逐点）。
- [ ] 把选择写进脚本注释与论文

> ⚠️ **训练与部署必须用同一个滤波器实现**。若训练用 `filtfilt`、设备用因果滤波，S1/S2 会错位，精度不可比。

**验收**：滤波前后各画 5 条波形对比；确认 50 Hz 干扰被压、S1/S2 形态保留。

## 6. 划分索引（1 小时）——**这一步最关键**

- [ ] **单位是录音**：先把 1,000 条录音分成 5 折 + holdout
- [ ] 先切 **holdout 15%**（=150 条，按类别分层 → 每类 30 条）
- [ ] 剩余 850 条做 **5 折分层**（每折 170 条，每类 34 条）
- [ ] 固定随机种子（如 42），**保存索引**
- [ ] **断言：同一录音的所有窗只出现在同一折**

`splits.json` 结构建议：

```json
{
  "seed": 42,
  "holdout": ["rec_0001", "rec_0007", ...],
  "folds": [["rec_0002", ...], ["rec_0003", ...], ["..."], ["..."], ["..."]],
  "created": "2026-10-29",
  "note": "recording-level, stratified by class"
}
```

**验收（四条全部通过才算完成）**

| 检查 | 通过标准 |
| --- | --- |
| 无泄漏 | 任一 recording_id 只出现在 holdout 或某一折中 |
| 分层 | 每折每类 34±2 条；holdout 每类 30±2 条 |
| 覆盖 | 1,000 条全部被分配，无遗漏无重复 |
| 可复现 | 用同一种子重跑，`splits.json` 完全一致 |

## 6.5 附加检查：固定窗 vs S1 对齐窗（**已移交 W2**，2026-10-30）

> W1 已于 2026-10-30 执行完毕（ADR-035～038），本检查依赖已冻结的 1,791 个窗，**放到 W2 做**，见 `w2-arms-checklist.md` §0。

**为什么加这一条**：27（LEPCNet）用 **Springer HSMM 分割**把每个窗对齐到心动周期，我们用固定窗——这可能是我们的劣势，且直接影响"部署后能否达到 27 的 95.6%"。

**做法（成本低，不重跑实验）**

- [ ] 在**已切好的窗**上，用现有的 S1/S2 检测（或简单能量峰）把窗**平移**到以 S1 起点对齐（不重新切窗）
- [ ] 用 **A1**（最快出结果的臂）分别在"固定窗"与"对齐窗"上跑 5 折
- [ ] 比较两者 macro F1

**判据**

| 差值 | 结论 |
| --- | --- |
| 对齐 > **1.5 点** | 对齐是必须补的一步，写入 W2/W3（占用降级顺序里的位置）|
| 对齐 0.5–1.5 点 | 作为可选增强，报在附录 |
| 对齐 < 0.5 点 | 不做对齐，论文里写明"固定窗与对齐窗无显著差异" |

**记录**：把两组的 macro F1 与差值写入 `w1-results.md`。

## 9. 常见坑（提前避开）

| 坑 | 后果 | 规避 |
| --- | --- | --- |
| 先切窗再划分 | 同录音的窗跨折 → **泄漏**（19 的错）| 先按录音划分，再展开成窗 |
| 用简单抽取降采样 | 混叠，高频伪造成低频 | 用 `resample_poly` |
| 训练用 filtfilt、部署用 lfilter | S1/S2 相位错位 | 两边同一实现 |
| 每折数量不均 | 某折某类样本过少，指标波动大 | 分层 + 断言 |
| 补零比例过高 | 大量零填充会引入"假静音"特征 | 记录并报告补零比例 |
| 每次重跑划分不同 | 结果不可复现 | 固定种子 + 保存索引 |
