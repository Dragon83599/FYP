# 参数基础：每个数字在干什么（写给"这个领域的小白"）

> 用法：**不用一次读完**。哪天要调哪个参数，翻对应那一节。
> 每节固定四行：**一句话 / 为什么需要 / 取大取小的后果 / 我们的取值**。

---

## 1. 采样率与 Nyquist

- **一句话**：每秒记多少个点。
- **为什么需要**：点越密越接近真实波形，但数据量、算力、内存都按比例涨。
- **取大取小**：太大浪费（44.1 kHz 对心音纯属浪费）；太小会"混叠"——高于一半采样率的成分会**伪装成低频**混进来。
- **我们的取值**：**2 kHz**。因为心音有效成分 <1 kHz（Nyquist 1 kHz 刚好）；1 kHz 会把 500–600 Hz 的杂音砍在边上（22）。

## 2. 帧长 / 帧移 / 加窗

- **一句话**：把长信号切成一小段一小段来分析（像用放大镜逐段看）。
- **为什么需要**：心音是**非平稳**的（频率随时间变），整段做 FFT 会糊成一片；切帧后每帧近似平稳。
- **取大取小**：帧太长 → 时间分辨率差（S1 和 S2 混在一帧）；帧太短 → 频率分辨率差（低音看不出）。
- **我们的取值**：**25 ms 帧 / 10 ms 移**（2 kHz 下 50/20 点）。25 ms 能分辨 S1 内部结构，10 ms 重叠保证瞬态不被切断。

## 3. FFT 与频谱

- **一句话**：把一帧波形变成"每个频率有多少能量"。
- **为什么需要**：很多病变是**频率特征**（杂音在高频），时域波形看不出来。
- **取大取小**：FFT 点数越多 → 频率分辨率越高，但每帧计算量越大。
- **我们的取值**：跟随帧长（50 点），做 64 个 mel 频带。

## 4. Mel 滤波器组

- **一句话**：把频谱按"人耳敏感度"重新分箱，低频细、高频粗。
- **为什么需要**：原始频谱维度太高（每帧 25 个频率点），且高频细节对判别帮助小；mel 把它压成几十维。
- **取大取小**：mel 越多 → 频率分辨率越高、维度越大；越少 → 越平滑。
- **我们的取值**：**64 个，上限 900 Hz**。0–900 Hz 上约 14 Hz 一格；A1 与 A2s **共用同一组 mel**，保证只差 DCT。

## 5. MFCC（倒谱系数）

- **一句话**：把 mel 频谱再做一次"逆变换"，得到描述**谱包络形状**的几十个数。
- **为什么需要**：谱包络（哪里隆起、哪里凹陷）比原始能量更能代表音色/病变；而且去相关、维度低。
- **取大取小**：维数越多越细，但后面的系数基本是噪声。
- **我们的取值**：**13 维**（语料里 13/17/19 都有人用；26 的网格显示 13–20 只差约 1 点）。

## 6. Δ / ΔΔ（动态特征）

- **一句话**：MFCC 的"一阶/二阶导数"，描述特征**怎么变**。
- **为什么需要**：杂音的**起始和终止**是重要线索，静态 MFCC 只描述"这一帧像什么"。
- **取大取小**：加上去维度 ×3；但有文献说静态已够（26）。
- **我们的取值**：**保留（39 维）**。除了捕捉瞬态，还有一个结构性理由：**A1c 需要 39×200 的二维输入**，只有 13 维的话 CNN 输入太薄。

## 7. 时间池化（均值 / 标准差）

- **一句话**：把 200 帧压成 1 个数（或两个）。
- **为什么需要**：让特征和"窗内位置"无关；分类器只吃固定维度的向量。
- **取大取小**：只取均值 → 丢失波动；加标准差 → 保留"能量起伏"（**杂音正是起伏**）。
- **我们的取值**：**均值 + 标准差**，MFCC 39 维 → 78 维；log-mel 64 维 → 128 维。

## 8. 卷积核 / 步长 / 通道

- **一句话**：卷积核是"放大镜的大小"，步长是"每次移动多远"，通道是"同时用几个放大镜"。
- **为什么需要**：让网络自己学局部模式（边沿、起伏），不用人工设计特征。
- **取大取小**：核越大 → 看得越宽（感受野大）但参数多；步长越大 → 输出越短、算力越省，但可能漏掉细节；通道越多 → 表达力强、参数和算力涨。
- **我们的取值**：2D 用 3×3、通道 8/16/32（小模型）；1D 用核 **40 点 = 20 ms**、通道 16/8/4（照 17）。

## 9. 感受野：为什么核长要跟采样率换算

- **一句话**：**核长（点数）÷ 采样率 = 覆盖多少毫秒**。
- **为什么需要**：换个采样率，同样的"点数"覆盖的时间就变了。
- **取大取小**：12.5 ms 太短（盖不住一个 S1 成分）；40 ms 可能跨过 S1 与 S2。
- **我们的取值**：17 在 1 kHz 用核 20（=20 ms）；我们在 2 kHz 用**核 40**（仍是 20 ms）——这样 A3 与 A3-repro **只差采样率**。

## 10. 池化 / 全局平均池化（GAP）

- **一句话**：池化是"取一小块里的最大值"，GAP 是"整张图取平均"。
- **为什么需要**：缩小尺寸、减少参数、抗位置偏移。
- **取大取小**：池化太猛 → 步数剩太少（信息丢）；GAP 代替 Flatten+FC → **参数量骤降**。
- **我们的取值**：2D 用 2×2 池化 + GAP；1D 用池化 4（照 17），**FC 128 保留**（为了和 17 可比）。
  - 代价：A3 的 FC 占了约 **80%** 的参数（31,872 / 39,557）——这是"可比性"换来的。

## 11. 参数量 vs 计算量（FLOPs/MACs）

- **一句话**：参数 = 模型"记了多少数"；计算量 = 跑一次"做了多少次乘加"。
- **为什么容易混**：两者不成正比。**计算量主要由输入长度决定**。
- **实例**：23（20,000 点）约 120 M MACs；27（1,500 点）1.59 M FLOPs——**参数差 5 倍，算力差 75 倍**。
- **对我们的意义**：**压输入长度比砍通道更省算力**。

## 12. batch / epoch / 学习率

- **一句话**：batch = 一次看多少样本；epoch = 把训练集看几遍；学习率 = 每步改多大。
- **取大取小**：batch 太小 → 梯度抖、训练慢；太大 → 小数据上更新太粗。学习率太大 → 不收敛；太小 → 收敛慢。
- **我们的取值**：**batch 32、最多 100 epochs、Adam 1e-3**（lr 取自 26）。

## 13. 早停 / 验证集

- **一句话**：在**验证集**上盯着指标，变差就停，取最好的那次。
- **为什么需要**：小数据容易过拟合；早停是最便宜的防过拟合手段。
- **关键纪律**：**验证集不是测试集**。测试集只在最后用一次。
- **我们的取值**：patience 10（连续 10 个 epoch 没提升就停），看验证 macro F1。

## 14. dropout

- **一句话**：训练时随机"关掉"一部分神经元。
- **为什么需要**：防止网络死记训练样本（1,000 条时很容易）。
- **取大取小**：0.5 太猛（浅层网络欠拟合）；0.1 太弱。
- **我们的取值**：**0.3**（FC 前）。

## 15. 过拟合与"数据量"

- **一句话**：模型把训练集背下来了，换数据就不行。
- **怎么看出来**：训练准确率 99.9%、验证 95% → gap 大。
- **和我们的关系**：1,000 条 + 五分类，**天然容易过拟合**；所以用小模型、dropout、早停、增强。
- **文献里的例子**：24（9.5M 参数）训练 99.883%、测试 98.879%，gap 约 1 点——算健康；19（增强泄漏）测试虚高到 99.87%。
