# 参数理由卡：每个取值，都能说出一句理由（2026-10-29）

> 用途：答辩/写论文时，被问"为什么是这个值"能直接回答。
> 每条格式：**取值 → 一句话理由 → 取别的会怎样 → 怎么验证**。
> 不依赖文献；文献依据见 `docs/parameter-ledger.md`。

---

## 一、预处理

### 1. 端点检测：帧长 25 ms / 帧移 10 ms / 阈值 = 噪声底 × 3

- **理由**：端点检测只需要"找到有声音的段落"，不需要精细时频分辨率；25 ms 帧覆盖一个 S1 的量级，10 ms 跳保证不会漏掉起止点；阈值取噪声底的 3 倍，是在"少剪"与"多剪"之间的常用折中。
- **取别的会怎样**：帧长 50 ms → 起止点定位变粗，可能剪掉杂音起始；阈值 ×2 → 容易把静音留下；×5 → 容易剪掉弱杂音。
- **怎么验证**：随机抽 30 条，比较"自动端点"与"人工标注起止"的时长差；若中位差 >100 ms，调阈值。

### 2. 特征帧长 25 ms / 帧移 10 ms

- **理由**：帧长要能容纳"一个心音成分"，又不能让 S1 与 S2 混在一帧；S1/S2 的单个成分约 20–150 ms，25 ms 落在下沿，保证不跨越两个成分。帧移取帧长的 40%，是为了让瞬态不被切断。
- **取别的会怎样**：0.2 s（26 的做法）→ 2 s 窗只剩 10 帧，均值/标准差统计不稳；10 ms 帧长 → 频率分辨率不足，低频杂音分不开。
- **怎么验证**：跑 25 / 50 / 100 ms 三档（各 1 种子 × 5 折），看 macro F1 是否在 ±0.5 点内；若差异大，说明结论对该参数敏感，需在论文中报告。

### 3. Mel 上限 900 Hz

- **理由**：采样率 2 kHz → Nyquist 1 kHz；把上限设在 900 Hz，给抗混叠滤波器留 10% 过渡带，避免最高几个滤波器实际被衰减成"空滤波器"。
- **取别的会怎样**：上限 1000 Hz → 顶部 3–5 个滤波器实际无能量，等效浪费维度；上限 600 Hz → 会削掉 600 Hz 以上的异常成分（22 指出异常可到 500–600 Hz）。
- **怎么验证**：打印滤波器组的中心频率与带宽，确认全部 <1 kHz 且最高一个的带宽不跨越 Nyquist。

### 4a. 滤波用零相位（sosfiltfilt）

- **理由**：心音的 S1/S2 相对位置与杂音时相（收缩期/舒张期）是判别信息；因果滤波会让不同频率成分延迟不同，**改变波形形态**。2 s 窗可以整段缓冲，所以零相位的代价付得起。
- **取别的会怎样**：用因果 `sosfilt` → S1/S2 整体后移，且低频延迟更大；若训练用 filtfilt、部署用 lfilter，**两边特征分布不一致**，精度不可比。
- **怎么验证**：同一段信号两种实现，比较 S1/S2 峰值位置偏移；设备端与 Python 逐点比对（误差 <1e-3）。

### 4. 带通 20–1000 Hz，4 阶

- **理由**：下限 20 Hz 去掉基线漂移与呼吸低频；上限 1000 Hz 等于 Nyquist，保留全部可分辨成分；4 阶是在"陡峭度"与"相位失真/计算量"之间的折中。
- **取别的会怎样**：上限 400 Hz（27 的做法）→ 可能削掉 AS/MR 的高频杂音；6 阶 → 更陡但相位失真更大，且端侧计算更贵。
- **怎么验证**：比较 20–400 与 20–1000 两档的 macro F1（各 1 种子）；差异 >1 点则说明高频有用。

## 二、特征

### 5. Δ + ΔΔ（39 维）

- **理由**：静态 MFCC 描述"这一帧像什么"，Δ/ΔΔ 描述"怎么变"；杂音的起始与终止正是变化点。另有一个结构性理由：**A1c 需要 39×200 的二维输入**，只有 13 维则 CNN 的输入过薄，2×2 不成立。
- **取别的会怎样**：只用 13 维静态（26 的结论是"静态足够"）→ A1c 变成 13×200，卷积核在频率轴上几乎无空间，A1c 与 A2 的对比会失真。
- **怎么验证**：A1 上加一组"13 维静态"的消融（1 种子 × 5 折），看差异是否 >1 点。

### 6. 时间池化：均值 + 标准差

- **理由**：均值编码"这一窗整体有多强"，标准差编码"强弱起伏"——而杂音的本质就是能量的异常起伏；两者合起来 78 维（A1）/128 维（A2s），维度可控。
- **取别的会怎样**：只取均值 → 丢失起伏，浅层分类器几乎无法区分"平稳的正常心音"与"波动的杂音"；取最大值 → 对单个噪声尖峰敏感。
- **怎么验证**：在 A1 上比"均值"vs"均值+标准差"（1 种子），差异应明显（预期 >2 点）。

### 7. Mel 64 个

- **理由**：0–900 Hz 上 64 个 mel 约 14 Hz 一格（低频更密），足以分辨杂音的频带位置；同时让 A1 与 A2s 共用同一组滤波器，保证两者只差 DCT 这一步。
- **取别的会怎样**：32 个 → 分辨率偏粗，600 Hz 附近的差异被合并；128 个 → 2 kHz 采样下高频已无内容，多出的维度是冗余。
- **怎么验证**：比较 32/64/128 三档在 A2 上的表现（1 种子），若差异 <0.5 点则保持 64。

## 三、模型

### 8. A1c/A2 用 8/16/32 通道

- **理由**：目的是让 2D 臂与 1D 臂**参数同量级**（约 6k vs 17k），这样"A2 vs A3"的差异才归因于表示，而不是模型大小；14/24 用的大通道会让 2D 臂参数高 1–2 个数量级。
- **取别的会怎样**：64/128/256 → 参数升到 10 万级，与 A3 不可比，且算力涨 10 倍以上。
- **怎么验证**：训练前打印参数量，确认 A1c/A2 在 5–8k、A3 在 15–40k 区间。

### 9. GAP + dropout 0.3

- **理由**：GAP 让参数量与输入尺寸解耦——若用 Flatten+FC，输入 64×200 会带来上百万参数（19 的教训：Flatten 后接 LSTM 直接上千万）；dropout 0.3 是针对"1,000 条小数据"的防过拟合设置。
- **取别的会怎样**：Flatten+FC → 参数暴涨、必过拟合；dropout 0.5 → 浅层网络收敛慢甚至欠拟合。
- **怎么验证**：看训练/验证 gap；若 gap >10 点，提高 dropout 或加数据增强。

### 10. A1/A2s 的搜索网格（C ∈ {0.01,0.1,1,10}）

- **理由**：4 档覆盖"强正则 → 弱正则"三个数量级，足以判断是否欠/过拟合；网格再大，内层计算量上升但收益递减（且 1,000 条数据下更细的网格容易过拟合验证折）。
- **取别的会怎样**：只试 1 个值 → 等于没调；10 档以上 → 内层折仅约 160 条训练样本，选择噪声大。
- **怎么验证**：记录每个内层折选中的 C；若多数折选到边界值（0.01 或 10），说明网格范围不够，需扩。

## 四、训练

### 11. batch 32

- **理由**：1,000 条、85% 训练 → 约 850 条，batch 32 得约 26 步/epoch，既能让 BatchNorm 有足够样本估计统计量，又保证每 epoch 有足够更新次数。
- **取别的会怎样**：batch 8 → 梯度噪声大、训练慢；batch 128 → 每 epoch 只有 7 步，小数据上更新太粗。
- **怎么验证**：看 3 个种子的 std；若 >2 点说明训练不稳，优先调 batch 或 lr。

### 12. 种子 3 个（42/123/2024）

- **理由**：用一个种子时，"A 比 B 高 1 点"无法区分是方法差异还是初始化差异；3 个是最小可用的重复数（能算 std，成本可控）。具体数值无意义，只是固定下来保证可复现。
- **取别的会怎样**：1 个 → 无法判断稳定性；5 个以上 → 训练量线性增加，收益递减。
- **怎么验证**：报各种子的 std；std 大则说明结论不稳健。

### 13. 最多 100 epochs + 早停 patience 10

- **理由**：100 是上限（26 的用法），早停保证不会白训；patience 10 意味着"连续 10 个 epoch 验证指标没提升就停"，对 1,000 条数据足够宽容，不会因一次波动误停。
- **取别的会怎样**：patience 3 → 容易早停；patience 30 → 浪费时间且可能过拟合。
- **怎么验证**：看早停 epoch 分布；若几乎都在 100，说明早停没生效（可能 lr 太小）。

## 五、评估

### 14. 外层 5 折

- **理由**：5 折每折训练 80%、测试 20%，在 1,000 条下测试折约 200 条（够算指标）；10 折会让每折测试仅 100 条、且训练次数翻倍（105 → 210 次）。5 折是"统计稳定"与"时间可行"的折中。
- **取别的会怎样**：10 折 → 指标略稳但训练时间翻倍；3 折 → 测试折 300 条但训练集少，偏差大。
- **怎么验证**：把 5 折的折间 std 报出来；若折间 std >2 点，说明划分敏感，可考虑 10 折。

### 15. holdout 15%

- **理由**：15% ≈ 150 条，足够覆盖五类（每类约 30 条）；同时留出 85% 给训练。比例再小则每类不足 20 条，CI 会很宽；再大则训练数据减少。
- **取别的会怎样**：10% → 每类 20 条，CI ±10 点以上；20% → 训练只剩 800 条。
- **怎么验证**：算 holdout 上每类样本数，确认均 ≥20。

### 16. bootstrap 1,000 次，按录音重采样

- **理由**：重采样单位必须是**录音**，因为同一条录音的多个窗高度相关；若按窗重采样，会把 1,500 个相关样本当成独立样本，CI 被人为压窄。1,000 次足以让 2.5%/97.5% 分位稳定。
- **取别的会怎样**：按窗重采样 → CI 偏窄、假阳性增加；100 次 → 分位数抖动大。
- **怎么验证**：跑两次 bootstrap，看 CI 上下限差异是否 <0.3 点。

### 17. 录音级聚合用 soft voting（概率平均）

- **理由**：多数投票丢掉置信度——一个 0.99 的窗和一个 0.34 的窗票值相同；概率平均让"确定"的窗权重更大，且单窗录音自然退化为窗级，规则统一。
- **取别的会怎样**：多数投票 → 两个窗冲突时靠平票规则，随机性大；取最大概率窗 → 会被单个过度自信的窗主导。
- **怎么验证**：同时算 soft voting 与 hard voting 的录音级 F1，若差异 >1 点，需在论文里说明选了哪个及理由。

### 18. 拒识阈值：训练折 BER 分位数，默认拒 10%；窗级

- **理由**：阈值必须来自训练折，否则等于用测试集调参（12/16 的错误）；按分位数而非绝对值，是因为不同数据集的 BER 尺度差异巨大（Yaseen 平均 707、PhysioNet 25）。默认 10% 是"先小步拒识、观察收益"的策略；窗级拒识让"覆盖率"口径唯一。
- **取别的会怎样**：固定绝对阈值 → 换数据集即失效；按录音拒识 → 需要先聚合再判，与窗级指标脱节。
- **怎么验证**：扫 5/10/15/20% 四个阈值，画覆盖率–F1 曲线；若拒 10% 时 F1 提升 <2 点，按 ADR-028 放弃拒识。

## 六、部署

### 19. 预热 10 次、重复 100 次、报中位 + P95

- **理由**：首次推理包含缓存未命中/时钟爬升，前几次明显偏慢（预热丢弃）；100 次足以让中位与 P95 稳定；报 P95 是因为用户感知的是"偶尔的慢"，不是平均值。
- **取别的会怎样**：只测 1 次 → 偶然性极大；只报均值 → 被长尾拉偏。
- **怎么验证**：两次独立测量，中位与 P95 的差异应 <10%。

### 20. 不报功耗

- **理由**：没有功率计，无法实测；引用文献值会造成"数据是我们测的"的误解。论文里只报精度、时延、RAM、Flash、体积——这些都能实测。
- **取别的会怎样**：引用 27 的 245 mW → 答辩被问"你测的吗"无法回答。
- **怎么验证**：若要补，需 USB 功率计；否则在论文写"功耗未测，参考 27 在 STM32F405 上的 245 mW"。

---

## 一句话总结

**每个参数的理由都落在三种东西上：物理尺度（时间/频率）、资源约束（算力/内存/时间）、以及"为了可比"（控变量）。** 说不出理由的参数，应该删掉或补理由——这是这份文档的用途。
